- 独立 reviewer 实读输入与产物，发现总计错误，给出 fail；主控记录 repair，交原执行者修正。
- 工具补齐执行基线后，两项在新尝试中实际重新执行/核对，旧尝试未回填基线；独立 reviewer 再查，当前结果通过。

- 实际 CLI 拒绝依赖尚未 verified 时启动下游、执行者自审，以及已验收后文件字节改变时 finish。恢复原已审字节后，再次 finish 成功。

## 适用边界

- 当前项目依赖 Codex 聊天中的主 Agent 调用工具；不是关闭聊天后继续工作的服务。
- 台账是单主控协作协议。不同姓名不能证明独立性，必须有实际派发；它不防御拥有同等写权限的恶意篡改。
- 影响结果的只读输入和交付文件必须完整申报，工具不会自动知道所有隐含依赖或外部事实。
- 符号链接真实逃逸测试未获得运行权限；硬链接别名未验证。超时终止直接子进程，不保证终止所有孙进程或远端任务。
- inspection 明确依赖领域审核，零条检查命令不伪装成测试通过。没有在本轮逐个登录或完成所有插件对应的真实业务。
- 原需求/spec 改变时新建 run；没有自动迁移既有任务定义的机制。大任务图的递归重核成本尚未做压力测试。
