## 第一版取舍

采用当前聊天的 Codex 原生子 Agent 与 [项目入口](../agent-workflow/SKILL.md)，保留现有工程、UI、视频和平台技能。一套主流程组织任务，独立 reviewer 检查真实产物；证据工具检查依赖、文件版本、实际测试日志、不同审查身份与重试上限。

任务状态及指纹是合作完整性检查，不是阻止拥有同等文件权限的 Agent 篡改状态的安全系统。身份必须来自真实宿主派发；填写不同字符串不足以证明独立审查。关闭聊天后的常驻执行不在本期。

运行验收与限制见 [协作验证记录](../agent-workflow/VALIDATION.md)。现有第三方技能和原视频代码保留；新项目技能不计入上述安装快照。

方法参考：[Codex Subagents](https://learn.chatgpt.com/docs/agent-configuration/subagents)、[Codex Skills](https://learn.chatgpt.com/docs/build-skills)、[Building effective agents](https://www.anthropic.com/research/building-effective-agents)、[LangGraph Fault tolerance](https://docs.langchain.com/oss/python/langgraph/fault-tolerance)。借鉴原生委派、评价修复、有限重试和去重思想，没有引入新的 Agent 框架依赖。
