# 动作提示词工程：从“画面在动”到“事情正在发生”

版本2026-11-13 R5.2。依据官方说明、创作者原文、制作复盘、社区失败记录和动画创作方法整理。本轮是资料研究，没有复现这些生成实验；作者报告的效果不写成我们的实测结果。逐项原链与读取范围见[研究来源索引](研究来源/00_来源索引.md)。

## 这轮对上一版的修正

R5.1解决了“有没有动作”，仍然没有充分解决“动作值不值得看”。推文件夹碰键盘虽有接触与结果，但视觉意外、隐喻层次与口播适配不足。不能把一次制作失败，修成全系列都只拍安全的小幅动作。

新的顺序是：**观众要理解什么关系 → 这个关系怎样改变世界 → 哪种媒介让变化最有力 → 怎样安排可读的动作 → 用哪些输入与提示控制 → 实际观看验证。**

R6.1默认宏大三维空间、强烈尺度反差与超现实结构变化。一个事件可以很大胆，例如字形凝成桥、桥解体成看不懂的字符；减少无关动作，而不是减少想象力。不同风格可以共存，但每镜的材质规则和整片的观看节奏要一致。

## 1. 连贯性至少有六种，不能混成一句“保持一致”

| 连贯性 | 要检查的事 | 首尾图通常解决不了什么 |
|---|---|---|
| 身份 | 同一个人、同一个对象，数量变化有原因 | 中途丢道具、脸漂移 |
| 空间 | 谁在左/右、前/后；轴线、路径与遮挡关系 | 脚穿台阶、手穿盘子 |
| 动作 | 起势、触发、发展、反应、完成 | 从准备姿势直接跳到结果 |
| 动势 | 位移方向、速度、动作相位和重量感 | 接缝忽然停住或反向 |
| 视觉 | 风格、光、色、景别和焦点组织 | 二维突然变写实；中途曝光变色 |
| 语义 | 因果顺序和隐喻规则不变 | 桥先塌了才出现触发；画面反而证明了口播正在反驳的观点 |

尾帧接首帧是位置锚点，不是速度与叙事的保证。来源：Styvid续镜对照、Curious Refuge机位修改复盘、社区H3续接记录；适用边界见各来源卡。

## 2. 把导演设计与模型提示分开

导演设计要完整：命题、转换规则、关键姿态、时间分配、必要不变量、首尾关系、字幕区和失败条件。给模型的文本则应围绕关键事件，避免把研究报告、所有技术验收和装饰形容词一股脑塞进去。

可用的动作语法：

> **主体与初态 → 触发 → 路径/变化前沿 → 次级反应 → 可见终态。**

例如“代码桥消失”尚不充分。可以设计成：近岸第一根字符梁先松开，松解沿桥向远岸推进；每段先失去横向连接，再散成原来的字形；人物在第一处空缺前收回脚步；远岸目标还在，过桥资格却不在了。这里的变化前沿、人物反应和残留结果，才让抽象隐喻成为事件。

这段描述是本项目原创设计范式，尚未生成验证，不是从作者作品抄来的已成功提示词。

## 3. “一个核心事件”不是“只能有一个动词”

一次跳跃可以包含蹲下、蹬地、腾空、落地、缓冲；一次桥的解体也可以有预兆、断联、散开、人物停步。它们是一件事的阶段。

五秒内让人物读完书、学会编程、造桥、过桥、签约，则是多件事争夺时间。需要省略、换镜或缩小本镜任务。不能为了“连续”强行一镜到底，也不能把关键因果切没了。

来源交叉：MiniMax与Runway对过程的要求、TheBabelfish_多动作失败记录、Curious Refuge分动作处理方法。不同作者的“一个动作”建议在这里解释为控制复杂度的方法，不升级成禁止动作链的铁律。

## 4. 用节奏制造刺激，不靠每处都动

动作至少区分三个观看节拍：**预期建立、主要变化、结果辨认**。预备可以很短，主变化可以突然加快，余动可以慢下来。不要把每个阶段平均分时，也不要所有元素从头到尾匀速漂动。

视觉刺激来自可读的强反差：有支撑变为悬空、细字变为巨大通路、平面突然产生深度、熟悉结构违反预期、一个东西变成另一个东西却保留共同轮廓。反差集中在主事件上，其他元素让路。

传统动画关于时长、间距、预备与余动的方法提供观看节奏的依据；它们不是模型参数，也不能保证文字写了就逐帧实现。参考Alejandro Garcia、Joey Korenman、Andrew Vucko的原文笔记。

## 5. 超现实与错误变形要分开

| 可用的设计性变形 | 需要修复的随机变化 |
|---|---|
| 字符按既定方向排列成桥梁 | 字符无缘无故变成汽车或乱码大字 |
| 同一笔墨从纸上升起，保持线条连续地成为道路 | 画面突然换了一条不相关的路 |
| 桥按规则解体，原字符仍可追踪 | 一闪白光后桥直接没了，过程缺失 |
| 二维角色保持扁平轮廓，夸张拉伸表达受阻 | 人物中途变成塑料3D模型 |

真实业务演示仍需真实结构与操作；艺术隐喻则维护自己的规则。不能以“物理合理”为由删掉用户要求的幻想，也不能以“这是艺术”为由放过无意的穿模、身份丢失和因果倒置。

## 6. 四层控制，失败时知道该改哪里

| 控制层 | 解决什么 | 使用条件 |
|---|---|---|
| 文字 | 意图、顺序、运动关系、规则 | 先简洁表达核心事件，必要时加约束 |
| 首尾/关键姿态图 | 起止构图、对象、姿态、变化边界 | 平台不支持中间帧时，中间姿态仍可用于内部设计，不能冒称已传入 |
| 动作参考/布局动画 | 节奏、轨迹、表演、接触 | 只有当前入口明确支持参考视频才提交；先说明借动作还是借外观 |
| 分层合成与剪辑 | 精确字形、局部修复、固定落点、视觉规则 | 用户需要的字形桥不必让人物、桥、文字、光全由一次生成解决 |

Tim Simmons的姿态/深度工具、Curious Refuge混合制作和Paul Trillo分层说明共同提供了“把需要的控制放进输入”的思路。但接受视频输入、姿态条件、深度条件是不同能力；不能因为底层H3有某模式，就宣称LibTV已支持。

如果同一失败重现，升级相应控制层。不要只叠加“更流畅、更自然、更电影感”。也不要先放弃精彩构思；先试能否把最难的转换拆成有共同关键帧的阶段或分层实现。

## 7. 首帧要给动作留出条件

首帧除了好看，还要让运动有地方发生：桥有可辨认的跨度，主体在手机尺寸下看得清，脚前有接触或空缺位置，字符有沿路径展开的空间。让视线先落在触发位置，再跟随变化到结果。

首尾图允许按设计改变结构、材质或空间；必须不变的是身份与映射关系，必须变化的是本镜要讲的事件。不要再写所有物体静止，同时又要求桥生成。

Bay的旧模型测试提示“小主体可能只运镜”；这是值得试验的构图假设，不是放弃远景或二维的定律。Curious Refuge的二维旋风案例也说明：有时过死的单张形状参考反而妨碍动作，需区分参考负责身份还是逐帧形状。

## 8. 镜头也可以讲故事，但要说明增加的信息

固定机位适合检查变化规则；跟拍可以让路径更可感；拉远可以揭露人物只是被一个局部假象困住；从字符内部穿出可以把“代码”变为“桥”的尺度揭露。不能将“不要只运镜”误改成“所有镜头都不得运镜”。

Loop Forge的走过镜头案例把相机转向放在人物经过之后：主体先行动，相机响应。可借用这类关系，但不照搬其种子、镜头方向或本地模型参数。

## 9. 给模型的可复用提示词骨架

### 单镜连续事件

> 【风格与首帧锚点】。【主体】从【初态】开始，由【触发】启动。先【预备/接触】，随后沿【方向/路径】完成【主变化】，带来【可见反应】；最后停在【结果】。相机【运动关系】，注意力落在【主事件】。保留【必要身份/空间/风格】，只按【明确规则】改变【允许变化部分】。

### 超现实生成/解体

> 【原材质】与【目标结构】由同一组可追踪元素组成。【触发】后，变化从【起点】向【终点】传播，每段先【中间状态】再【完成状态】；其他部分仍保留原样，直到变化抵达。主体对正在发生的变化做出【反应】。结束时看清【新关系】，不是闪白或硬切到另一张图。

### 动作参考（能力需先核验）

> 视频参考负责【轨迹、节奏和接触】，图片参考负责【角色/材质/场景】。延续【具体区间】的动作相位，改变【明确对象】，保留【方向、相机关系、关键事件先后】。不要只笼统写“参考这个视频”。

### 跨镜交接

> 前镜结束时【主体姿态、位置、速度方向和未完成动作】；后镜从该动作的【阶段】接入，以【新景别/视角】继续到【结果】。此次剪切新增【信息】，省略【时间】，不省略【关键因果】。

这些是工作模板，不是平台特殊语法。帧数和精确时间由剪辑保证；时间码仅帮助模型理解顺序。

## 10. 对照试验与拒收条件

先做三种不同构思的小样设计，不必立刻付费生成。选定命题后再以同首帧、同设置比较两个动作描述；平台支持种子时记录种子，不支持时记录多次随机性。不要一边换首图一边换模型，再归因于某个词。

| 失败表现 | 优先诊断/修正 |
|---|---|
| 只有相机动 | 主事件是否写清、主体是否可辨、首帧是否支持动作 |
| 先结果后触发 | 把接触/条件变化写前；检查首帧是否已完成；安排中间姿态 |
| 桥凭空换形 | 明确元素映射与变化传播方向，必要时分层控制 |
| 动作在剪点后才完成 | 改选真实完整区间，或减步骤/重做局部；不动原口播速度 |
| 续镜布局对但动势断 | 对齐速度、方向与相位；检查前后连播，不只单看首尾 |
| 主体动作对但二维变3D | 把材质规则作为不变量，检查参考是否暗示写实化 |
| 没有意思但很流畅 | 回到命题与口播立场，不再堆特效掩盖概念薄弱 |

验收必须分别记录：语义适配、视觉发现、完整事件、运动连续、材质保持、技术参数。前五项不能被“已生成成功”“无黑帧”“音轨哈希一致”替代。研究笔记和提示词不是视频通过的证明。

## R6.1 三合一创作增补（巫师三母本＋动作补强＋≥200字高密度细节）

- **三大母本与物件完全自由**：结合 `05_创作参考/让画面有第二层意思_巫师财经总纲.md`、`05_创作参考/视觉语言百科_v2.2/00_开始使用.md`、`05_创作参考/15支视频物体视觉方法/02_物体空间与镜头表现.md`（已剔除阿畅）。口播是创作输入，独立核实不是生图前置条件；**不规定、不限制具体使用什么物件、材质或场景，由 AI 根据当期口播关系与潜台词自主构思**。
- **首帧即奇观＋单向五步连续动作补强**：独立生成镜头（尤其 `G01` 首镜）第 `0.0` 秒**首帧本身必须已同场立住超现实尺度反差或结构异变**（严禁把首帧画成普通日常白墙、门口拿手机或正常办公照，把奇观留到尾帧）；首尾帧必须构成**单向不可逆物理状态差**（严禁“完好→崩塌→完好”U型折返陷阱），落实“奇观蓄势初态 → 可见触发与物理接触 → 单向主变化推进 → 次级物理反应 → 终态减速停留”。
- **≥200字高密度细节门槛＋零工程词污染**：每条首帧、同源尾帧、视频运动提示词均须写满 ≥200 个纯中文字符的可见场景、尺度参照、材质纹理、光线与动作细节，**严禁混入 `字幕`、`y1440`、`后期图层`、`乱码`、`假字` 等工程指令词**（底部留空直接描写干净平整的前景地面或台面材质）。
