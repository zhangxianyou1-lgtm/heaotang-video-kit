## 06 把百科用于分镜、制作与检查

### 06.1 分镜记录

按完整意思单元组织，不为填表把每句话切成一个镜头。关键段落保留构思理由，常规过渡可简写。固定阶段见 [00 入口](00_开始使用.md)：V1 先完整覆盖当前要求范围，只需原文对应、观看目标、自己的场面与事实限制；下表其余技法、路线和制作字段在定向查阅后补入 V2，不为填这些字段提前读取方法与案例。

| 字段 | 填写内容 |
|---|---|
| 镜号、原文、说话人 | 锁定口播逐段保留；新增屏幕字另列 |
| 版本与修订依据 | V1 与 V2 的版本、文件位置；主要改动、借鉴条目及修改理由；未改镜头可标保留 |
| 观看任务 | 本镜让观众理解或感受到什么；对应 F 功能 |
| 语义关系 | 用普通话说明主关系，可附 R 编号 |
| 自己的场面构思 | 对象来自哪里；起始状态、变化、结果或静态关系 |
| 备选与选择依据 | 关键镜头至少比较不同表达机制；普通延续镜头可省略 |
| 查到的技法 | G 编号、适用条件；说明借了哪种组织方法 |
| 继承与新增理解 | 跨镜解释时填写：观众已知道什么，本镜新增什么，哪些对象与编码保留 |
| 原创转化记录 | 与已参考作品在哪些具体表达上独立设计；未查则标明 |
| 事实与材料 | 真实记录、引用、演示、推演或隐喻；证据支持的范围 |
| 路线与资产 | T 路线可混合；各层任务、已具备与待准备资产 |
| 声画时间 | 正式音轨时间点，或明确标记的估算预算 |
| 最关键的检查 | 能从实际画面判断的成功条件，失败后优先修改什么 |

锁稿检查应逐段比较原文，排除排版空白后核对文字和说话人；不能把语义摘要当成新的口播稿。时长不足时优先提前建立对象、跨句保留结果或删去次要动作。未经用户允许，不借制作困难删改锁定口播。

### 06.2 给执行者或生成工具的镜头任务

需要生成视频时，按下列职责组织输入；可按已选技法读取 [08 提示词卡](08_视频生成提示词卡.md)。

| 输入或交付 | 职责 |
|---|---|
| 首帧制图说明 | 起点构图、主体身份、材质、空间与光向 |
| 可选尾帧制图／编辑说明 | 在同一套主体与场景基础上派生终态；何种结果必须看见 |
| 运动说明 | 主事件、先后、运镜、保持项与结果停留；时间描述作为意图，准确节奏后期调整 |
| 后期说明 | 精确文字、数字、关系、声音及其透视、遮挡与出现时机 |

简单动作或探索性运镜可只用首帧；终态承担重要含义时考虑首尾帧；多次因果转折可拆镜。两张关键帧不能保证中间路径，实际输入方式以当前模型支持为准。无需为每镜先生成一段参考视频；确有复杂动作参考需求时再准备有来源依据的参考。先检查画面，再测试最难的运动，保持有意义的大动作目标。

```text
镜头编号与目的：
对应原文与主功能：
抽象关系及必须保留的限制：
主体与环境：本稿对象、身份、数量、材质、空间与光向。
起始状态：先让观众辨认什么。
关键变化：触发、行为、响应及先后；静态画面写出观看关系。
结果状态：最终看清什么，哪些仍未解决。
相机与焦点：固定或移动；变化揭示什么；何时允许阅读。
保持不变：对象身份、比较条件、结构、来源等。
信息层：中文、数值、标签和字幕分别由什么受控方式制作。
来源性质与素材依据：真实／引用／示意／重建／隐喻。
制作分工：T01–T05 各层职责与接合条件。
静帧动态化时补充：静帧本身承担什么；选择平面运镜、分层视差、局部合成还是图生视频；运动新增的作用与允许显露的空间。
借鉴方法：采用哪项 G 操作，具体画面怎样独立构思。
验收条件：语义、原创转化、静帧、动作、阅读、声音。
未通过后的处理：修资产、改动作或换路线，哪些表达目标必须保留。
交付状态：方案／静帧／动态样片／待检查成片／已检查成片。
```

没有工具支持的控制项写成目标与待验证条件，不假造 API 参数。任务书中的“电影感、精致、流畅”可作倾向，但不能代替资产要求和可见检查条件。

### 06.3 检查顺序与处理办法

| 层级 | 应当回答的问题 | 明显不满足时的处理 |
|---|---|---|
| Q01 语义 | 画面是否表达本段关系与情绪？是否偷换或加强了口播？ | 改构思或缩回事实范围，暂不批量制作 |
| Q02 原创转化 | 方案是否只是参考的换皮？具体组合是否由本稿重新设计？ | 回到语义卡，重新选择场面与观看顺序 |
| Q03 证据 | 成功、数字、结构、客户和参与关系有何依据？ | 换真实资料或标清示意，保留尚未验证部分 |
| Q04 美术 | 在最终尺寸下，主体、材料、光向、空间和阅读重点是否达到本片目标？ | 修资产和构图或换路线，不能用动效掩盖 |
| Q05 动作 | 起始、接触、响应、结果的身份与因果是否成立？ | 查关键姿态与连续过程，修穿插、时序和漂移 |
| Q06 信息 | 必要中文、单位、比例和关系能否在正常播放时读清？ | 减少并行信息，保留参照，调整布局和停留 |
| Q07 声画 | 实际听看是否有截字、重复声音、口型或节拍问题？ | 使用实际音轨重新对齐；未听审不写通过 |
| Q08 导出 | 实际交付文件是否完整、可播放且与检查版本相同？ | 检查导出文件本身，版本改变后重查受影响部分 |

技术检查、截图检查、原速连续观看、实际听审是不同证据。截图可发现材质与构图问题，不能单独证明整段节奏自然；音频峰值检测不能证明配音自然；“文件存在”和“渲染成功”不能替代任何美术验收。

如果目标是精修成片，已经明显影响观感的资产粗糙、构图失焦或动作看不清，不应自动列成“非阻断”。若当前交付只是机制练习或预演，明确标签，避免它未经复查就流入正式成片。

### 06.4 少量代表性验证，再扩展

先从当前稿件选择能暴露主要难点的段落，例如一个情绪或空间场面、一段准确关系解释，以及一个必须证明真实过程的片段。它们是按需要选择的验证点，不是每条视频必须凑齐的三种风格。

验证顺序：场面含义 → 独立构思 → 最终关键静帧 → 最难动态 → 声画和成片。通过后复用已验证的资产、色彩职责、信息层与制作方法，不机械复用整套镜头。

新增方法按实际使用分支检查，不要求每条视频全部执行：

- **连续追问与换图：**问题在本段是否得到回答；新图究竟解决什么比较任务；对象颜色与含义是否延续；分母、单位、时间或样本口径改变时是否交代。锁稿内容保持一致。
- **总图回收：**总图是否回收已经解释的节点与关系；新连线是否有依据；最终尺寸下能否辨认主要路径。概览只负责定位时，不要求观众同时读取缩小后的全部数字；已无新增理解就不强行加总图。
- **静帧动态化：**先对照静止版本，确认运动有观看作用，再检查裁切分辨率、抠图边缘、遮挡区域、视差方向和局部光影。原速观看运动边界，不能仅凭首尾截图宣布无穿帮。
- **生成情境：**验证真正承担含义的动作和空间变化；检查主体身份、场景连贯性与结果。图生视频即使使用已确认关键帧，仍需复查中间过程。各镜通过条件取决于叙事任务，不为省生成次数接受不成立的画面。

多人或多 AI 协作时，由当前 V2 或其后续修订分镜和同一组已检查的视觉样本定义目标，V1 独立留档。每个任务交付包含实际文件、资产来源、版本与未通过项。并行数量不代表效率或质量；共享资产和重要条件变更后，检查受影响镜头，避免不同任务各自解释为不同风格。

### 06.5 原创与质量分开核对

原创方案可能粗糙，精致画面也可能照搬。分别记录：

- **表达独立性：**本稿的对象、情境、构图、动作与镜头组合怎样形成；与已用参考的具体重合怎样处理。
- **制作完成度：**实际画面能否达到本片的语义、美术、动作与阅读目标。

“未发现明显照搬”只限于已经对照的参考与范围，不写成与所有作品都不同。“好看”也不允许掩盖事实错误、数据口径不一致或技术机制不成立。

### 06.6 建议的交付说明

```text
完成内容：本次实际交付了什么，哪些镜头与版本。
实际检查：看过的静帧、连续片段、音轨与导出版本。
原创对照：查过哪些参考、具体重合如何处理、范围有什么限制。
事实依据：真实来源和明确示意分别是什么。
剩余问题：未完成或未验证的事项，以及影响哪一部分。
```

制作反馈按 [07.3 新条目与实测回写](07_学习与来源.md#feedback)记录。原始 V1 与最终分镜保留在项目中，百科只吸收可迁移的方法、条件与验证经验。

复用资产时保存可读的用途、版本、来源、适用范围和已知问题。不把某次审片的“通过”永久赋给同名文件；新的构图、机位、时长或数据可能需要重新检查。
