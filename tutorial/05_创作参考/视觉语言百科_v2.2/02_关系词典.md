## 02 抽象关系词典

这些条目是编者从既有研究提炼的设计建议，帮助 AI 判断台词中的关系，不是原作者的镜头模板或创作事实。例子均为示意，不代表已发生的项目。

先完成本稿的语义判断，再按关键词查相关条目。关键词仅帮助检索；同一个词可能承担情绪、事实或机制等不同任务，不能凭命中词条直接选图。每条提供的两个视觉候选都是起点，实际对象、场景、顺序和构图由本期内容重新决定。一个镜头通常选一个主关系，相关条目用于必要的补充，不要求全部采用。

<a id="r01"></a>

### R01 压力与承载

类别：处境与感受。检索词：负担、容量、来不及。

**关系含义**：外部要求占用主体有限的时间、精力或处理能力；重点是要求与可用能力的关系。
**何时查阅**：台词强调事情增加而人手、时间不变；需要观众认出被工作挤压的处境。
**必须保留**：明确谁承担什么，原有任务仍然存在；心理压力的示意不充当系统容量或效率证据。
**视觉候选（重新设计后采用）**：

- 在同一工作日时间带上保留既有任务，让新增事项挤占原先的可支配时间。
- 保持人物或实际工作区域不变，让周围待处理业务逐渐侵入可操作空间。

**容易误用**：见到“压力”就固定使用压机或坠物；只展示沉重，却看不出谁承担了什么。
**完成检查**：观众能指出负担来源、承载主体，以及哪项余量减少了吗？
**相关条目**：[R02](#r02)、[R07](#r07)、[R18](#r18)。

<a id="r02"></a>

### R02 累积

类别：处境与感受。检索词：越来越多、积压、重复发生。

**关系含义**：多次事件的结果持续留下，使当前状态区别于初始状态；累积可能是负担，也可能是成果。
**何时查阅**：台词强调长期、反复或越做越多；单次事件不足以解释当前处境。
**必须保留**：每次新增都保留此前结果，移除时说明原因；次数、数量或速率若无依据，保持定性示意。
**视觉候选（重新设计后采用）**：

- 从当天的一条未处理记录展开到同一系统中的历日积压，保留日期与处理状态。
- 同一空间里逐次留下处理痕迹，最后回到初始视角显示环境已经改变。

**容易误用**：每次切镜把结果清零；用无限复制夸大真实规模；把累计量画成当前流量。
**完成检查**：能从最后状态找回此前发生的事，并区分新增、已处理和剩余吗？
**相关条目**：[R01](#r01)、[R24](#r24)、[R40](#r40)。

<a id="r03"></a>

### R03 进入门槛

类别：处境与感受。检索词：入门、资格、从哪里开始。

**关系含义**：主体想接近目标，却受到知识、权限、资源或自我判断的限制；先分清真实限制与感受到的困难。
**何时查阅**：台词谈开始一件事所需的条件；观众把陌生感误当作没有资格。
**必须保留**：降低一种门槛不等于全部条件消失；现实授权和能力要求不能被画面擅自取消。
**视觉候选（重新设计后采用）**：

- 把目标任务拆出一个可先尝试的局部，其他条件继续留在整体中。
- 从本业务中选择一种实际操作情境，先呈现完整环境，再让主体已能尝试的局部变得可接近，其他条件继续留在视野里。

**容易误用**：所有门槛都画成门或台阶；让障碍瞬间消失，暗示无需学习、权限或投入。
**完成检查**：观众知道现在可以开始哪一步，也知道还有哪些条件要满足吗？
**相关条目**：[R06](#r06)、[R12](#r12)、[R36](#r36)。

<a id="r04"></a>

### R04 靠近与退缩

类别：处境与感受。检索词：想试、犹豫、算了。

**关系含义**：主体对目标的投入意愿发生变化；表达的是注意、行动或心理距离，不等于目标的实际价值变化。
**何时查阅**：一段口播从好奇走向尝试或放弃；需要交代同一个人态度转折。
**必须保留**：保留目标身份，让转变有可见原因；不凭配色或退镜给真实人物捏造心理活动。
**视觉候选（重新设计后采用）**：

- 同一任务从旁观展示进入可操作视角；遇到明确困难后，操作停住，注意力回到未完成的本职工作。
- 用真实讲述者的停顿、视线与环境留白承接态度变化，资料画面随关注点退出。

**容易误用**：只有推近拉远却没有态度转折依据；把退出一次尝试解释成永久失败。
**完成检查**：观众能说出是什么让主体靠近或退开，而不是仅看见镜头运动吗？
**相关条目**：[R03](#r03)、[R05](#r05)、[R08](#r08)。

<a id="r05"></a>

### R05 期待落差

类别：处境与感受。检索词：本来以为、结果却、反而。

**关系含义**：预期与随后显露的实际状态不一致；重点是落差发生在哪个条件、成本或结果上。
**何时查阅**：台词明确给出预期与实际的转折；需要揭示宣传印象遗漏的工作。
**必须保留**：预期和实际指向同一目标与比较范围；没有证据的期待仅作为人物主观想法或情境示意。
**视觉候选（重新设计后采用）**：

- 先建立预计完成的任务范围，再显露实际新增的核对、修改和交付环节。
- 保持原有工作对象不变，让新出现的学习要求逐渐占据它的操作空间；构图从预期的松动转为更拥挤，明确这是感受示意。

**容易误用**：先造出虚假的完美承诺再推翻；仅靠突然变暗或爆炸制造不存在的反转。
**完成检查**：预期是什么、实际多了或少了什么、落差来自哪里，都能被指认吗？
**相关条目**：[R01](#r01)、[R27](#r27)、[R35](#r35)。

<a id="r06"></a>

### R06 不确定

类别：处境与感受。检索词：不知道、可能、待验证。

**关系含义**：关键信息、适用条件或结果尚未确定；不确定应落在具体未知项，而不是笼统涂成迷雾。
**何时查阅**：观众不知道工具与自己任务如何对应；方案已提出但还没有现场验证。
**必须保留**：已知与未知同时存在并保持区别；未知不能被画成失败，也不能用平滑动画偷换成成功。
**视觉候选（重新设计后采用）**：

- 并列当前任务与已知能力，只有得到证据的对应关系连接，未验证关系保持待测标记。
- 在本业务场景中保留清楚的任务对象，视线在几个可能入口之间尝试却无法接续；镜头最终停在具体缺失条件上。

**容易误用**：满屏问号遮住实际问题；把未知概率画成确定比例；用黑暗暗示方案必然不可行。
**完成检查**：观众能列出一个具体未知项，以及获得什么信息后才能继续判断吗？
**相关条目**：[R13](#r13)、[R28](#r28)、[R38](#r38)。

<a id="r07"></a>

### R07 注意力过载

类别：处境与感受。检索词：看不过来、术语太多、被打断。

**关系含义**：同时竞争注意的内容超出当前阅读与判断需要，使主任务难以持续；它不等同于信息总量大。
**何时查阅**：台词强调频繁切换、陌生概念并发或找不到重点；需要建立工作中的认知负担。
**必须保留**：观众仍应看清主任务如何被干扰；用短暂受控的拥挤表达过载，不让整段真的无法阅读。
**视觉候选（重新设计后采用）**：

- 保持正在处理的实际工作对象在前景，外围任务依次进入操作区，原动作反复中断；用视线落点与局部照明交接注意，主任务始终可辨。
- 先展示内容相近却分类混乱的资料，再只圈出当下需要解决的问题，形成主次差异。

**容易误用**：把很多字快速飞入当成复杂知识；干扰层一直盖住口播重点；把所有资料都说成无用。
**完成检查**：能看出主任务、打断来源和损失的连续性，而不必读完全部干扰项吗？
**相关条目**：[R01](#r01)、[R30](#r30)、[R31](#r31)。

<a id="r08"></a>

### R08 控制感

类别：处境与感受。检索词：心里有数、掌握、可检查。

**关系含义**：主体能够识别状态、选择下一步并检查结果，因此对行动更有把握；控制感来自可理解的反馈。
**何时查阅**：台词从无从下手转向可以逐步尝试；强调检查、回退和人能够做的判断。
**必须保留**：保留系统仍有限制的事实；人物的把握感不等于方案已经获得长期成功验证。
**视觉候选（重新设计后采用）**：

- 同一任务先只见模糊目标，随后出现可执行的小步骤与明确检查点，每次只推进一项。
- 在实际工作场景中，从远处难以判断的整体切到主体能操作的一小段；一次试探动作产生可辨反馈，回到全景时保留这块已掌握范围。

**容易误用**：让一个按钮自动完成所有任务；用发光或欢呼代替检查结果；暗示人已无需理解工作。
**完成检查**：观众能指出主体现在掌握了什么，以及下一次出错时能在哪里检查吗？
**相关条目**：[R19](#r19)、[R20](#r20)、[R39](#r39)。

<a id="r09"></a>

### R09 竞争

类别：主体之间的关系。检索词：争抢、替代、相互制约。

**关系含义**：两个或多个主体对有限资源、机会或选择权提出不同要求，一方行动改变另一方的可得条件。
**何时查阅**：台词明确存在共同争取对象；需要解释竞争怎样改变资源分配。
**必须保留**：指出竞争的对象与规则，不预设必为零和；区分竞争、直接冲突与可以共存的差异。
**视觉候选（重新设计后采用）**：

- 把两套工作安排放进同一有限时段，展示一方占用后另一方可用时段如何变化。
- 在按本稿重新设计的空间中，让两项业务行动使用同一有限工作区域，一方占用后另一方的可用位置或等待状态随之变化。

**容易误用**：听到竞争就让旗帜、拳头或车辆相撞；把正常选择画成恶意攻击；用胜负特效替代规则。
**完成检查**：不看阵营符号，仍能理解争的是什么、谁的条件怎样改变吗？
**相关条目**：[R11](#r11)、[R15](#r15)、[R37](#r37)。

<a id="r10"></a>

### R10 合作

类别：主体之间的关系。检索词：共同完成、互补、帮手。

**关系含义**：不同主体分别承担某些工作，共同形成单独一方难以完成或代价更高的结果；贡献仍有边界。
**何时查阅**：说明人和工具、团队成员或部门如何互补；需要让各方贡献可见。
**必须保留**：分别交代输入、职责和连接方式；合作结果不能抹去仍由人承担的核验与责任。
**视觉候选（重新设计后采用）**：

- 在实际业务场景中，让不同主体对同一对象完成各自一段动作，交接处保留身份与状态，最后让共同结果与最初问题同框。
- 在共同目标旁保留各方独立可完成的部分，连接后才出现新增能力。

**容易误用**：把握手、并排站立当成合作机制；让辅助方取代全部工作；贡献划分没有事实依据。
**完成检查**：观众能复述各方分别做了什么，缺少其中一方会少哪一步吗？
**相关条目**：[R12](#r12)、[R14](#r14)、[R19](#r19)。

<a id="r11"></a>

### R11 不对称

类别：主体之间的关系。检索词：差距、优势、信息不对等。

**关系含义**：主体之间在规模、信息、权限、成本或选择空间上存在差异；差异可能决定行动能力。
**何时查阅**：台词比较各方条件而非仅比较最终结果；解释为何相同动作对不同主体效果不同。
**必须保留**：只把有依据的维度表现为大小或范围差异；视觉尺寸不同时暗示财富、道德和能力等所有维度。
**视觉候选（重新设计后采用）**：

- 同一业务地图分别显示两方可见信息范围，保留共同区域以说明差异来自权限。
- 用同一业务场景中可操作空间、可见范围或调度余量的差异表现条件不对等；精确差距另用同尺度数据验证。

**容易误用**：大人物必然正确、小人物必然弱；放大体积却不说明比较指标；用夸张比例伪装数据。
**完成检查**：观众能明确说出哪一种条件不对等，而非只记得一大一小吗？
**相关条目**：[R09](#r09)、[R15](#r15)、[R33](#r33)。

<a id="r12"></a>

### R12 依赖

类别：主体之间的关系。检索词：前提、缺一不可、要先有。

**关系含义**：某个结果成立，需要一个或多个条件持续满足；必要条件与足够条件要分别表达。
**何时查阅**：说明项目实施需要数据、权限或硬件条件；解释一个环节为什么不能单独完成目标。
**必须保留**：明确依赖方向和条件范围；满足一项必要条件不能画成全部成功条件已经齐备。
**视觉候选（重新设计后采用）**：

- 目标结果旁显示所需输入，逐一对应当前已具备和缺失项，缺项影响的步骤保持待完成。
- 在真实流程中暂时移除一个前提，展示受影响的局部，再恢复相同条件验证变化。

**容易误用**：所有依赖都画成一根断链；把相关性当必要性；条件满足后让未验证结果自动变绿。
**完成检查**：观众能指出缺的是哪个前提、影响到哪里，而不是误以为补齐它就万事完成吗？
**相关条目**：[R03](#r03)、[R13](#r13)、[R36](#r36)。

<a id="r13"></a>

### R13 断接与不兼容

类别：主体之间的关系。检索词：接不上、格式不同、无法对接。

**关系含义**：一端已有输出，另一端有接收要求，但二者在格式、语义、权限或时机上不匹配。
**何时查阅**：工具看似可用却不能进入现有工作；解释数据在两套系统之间停住的原因。
**必须保留**：具体指出不匹配的是哪一层；修正匹配不自动证明后续业务和长期运行均成功。
**视觉候选（重新设计后采用）**：

- 并排显示一个字段的输出格式与接收规范，让失败停在实际校验位置，修正后重试同一条数据。
- 以业务对象的状态标记追踪交接，清楚区分已生成、已发送、已接收和已入账。

**容易误用**：所有对接问题都套成插头插不进；让一个适配器代表全部集成工作；错误原因只写问号。
**完成检查**：观众知道两端分别有什么，究竟哪条要求没满足，以及本次修复覆盖多大范围吗？
**相关条目**：[R06](#r06)、[R12](#r12)、[R19](#r19)。

<a id="r14"></a>

### R14 协同

类别：主体之间的关系。检索词：配合、同步、各环节衔接。

**关系含义**：多个环节按照时间、状态或资源约束配合，局部正确还需要整体协调才能产生有效结果。
**何时查阅**：每个组件都能工作但整体仍卡住；说明多人或多系统如何协作运行。
**必须保留**：保留各环节各自节奏和职责；区分真正需要同步的动作与只需按条件交接的动作。
**视觉候选（重新设计后采用）**：

- 在共享时间线上展示各环节就绪、等待与接续，调整一处时序后验证整体等待变化。
- 从本业务选择多个确需配合的动作，保持统一空间参照，先显露相互等待，再调整配合点，观察整体如何接续。

**容易误用**：所有元素同拍运动就称协同；把异步流程画成瞬间完成；省去等待与异常分支。
**完成检查**：能指出需要配合的约束，以及局部正确为什么仍可能无法形成整体结果吗？
**相关条目**：[R10](#r10)、[R17](#r17)、[R18](#r18)。

<a id="r15"></a>

### R15 分配

类别：主体之间的关系。检索词：份额、资源、时间花在哪里。

**关系含义**：一个明确的总体被分到不同主体或用途；改变分配会影响各部分的可用量与剩余量。
**何时查阅**：比较投入结构、预算分配或时间去向；解释资源有限时各方如何获得份额。
**必须保留**：先定义总体、单位和时间范围；同一总量下的增减应守恒；总量变化另行呈现。
**视觉候选（重新设计后采用）**：

- 同一工作时段中保留找资料、核验、写作等用途，调整分界并展示总时长是否变化。
- 用共享资源池与各去向表示分配规则，尚未分配部分留在原处。

**容易误用**：没有测量却给出精确占比；一项增大而总量与其他项都不变；把预算等同利润。
**完成检查**：各部分是否能合回定义的总体，数值和定性示意是否明确区分？
**相关条目**：[R09](#r09)、[R34](#r34)、[R35](#r35)。

<a id="r16"></a>

### R16 交换

类别：主体之间的关系。检索词：付费、交付、价值换取。

**关系含义**：主体提供某种资源、工作或结果，以获得另一项回报；需要说明交换双方及各自认可的价值。
**何时查阅**：解释客户为什么愿意付费；讨论交付物、服务范围和回报的对应。
**必须保留**：区分报价、合同金额、实收与利润；交付价值须对应需求和验收依据，不能只靠金额特效。
**视觉候选（重新设计后采用）**：

- 有真实项目材料时，回到原来发生麻烦的工作位置，展示改善后的处理动作与验收；付费关系在结果被认可后再建立。
- 把服务清单与对方得到的具体改变并列对应，保留未包含的维护或额外需求。

**容易误用**：金币流入代替付费理由；工具打开后立即出现收入；把示意交易包装成真实客户项目。
**完成检查**：观众知道谁为哪项结果付费，也能区分已发生交易与方案推演吗？
**相关条目**：[R10](#r10)、[R35](#r35)、[R40](#r40)。

<a id="r17"></a>

### R17 先后

类别：过程与变化。检索词：先做、顺序、之前之后。

**关系含义**：事件按照时间或条件排列；调整先后可能改变学习负担、返工或结果，但先发生不自动代表导致。
**何时查阅**：台词要求换一种行动顺序；需要说明某步骤为何必须在另一项之前。
**必须保留**：保持步骤身份，明确时间先后还是逻辑前提；若声称顺序带来效果，提供原因或验证而非只调位置。
**视觉候选（重新设计后采用）**：

- 保留同一组实际步骤，对照两种安排中何时产生可检验结果，显示减少了哪次无效等待。
- 沿同一任务展示开始、触发条件和后续动作，使箭头只连接真实发生的交接。

**容易误用**：把名词卡片换位就宣称效率提高；倒放动作冒充新流程；把时间相邻当作因果。
**完成检查**：观众能辨认具体换了哪一步，以及这种调整改变了什么条件吗？
**相关条目**：[R12](#r12)、[R14](#r14)、[R32](#r32)。

<a id="r18"></a>

### R18 瓶颈

类别：过程与变化。检索词：卡住、排队、最慢的一步。

**关系含义**：整体推进受到某个环节的能力、等待或限制牵制；增加其他部分能力未必改善整体结果。
**何时查阅**：解释自动化后为什么仍然慢；决定先改哪个环节才有实际帮助。
**必须保留**：把瓶颈定位到具体流程与条件；改善一处后应继续检查是否出现新的限制。
**视觉候选（重新设计后采用）**：

- 在业务时间线上区分处理与等待，突出等待集中在哪里，保持其余步骤作为参照。
- 在真实现场或明确示意的业务空间里保留同一批待处理对象，显露限制环节前的积压与后方空闲；数量和提速另行核实。

**容易误用**：所有卡点都画成窄管；仅提高识别速度就声称整个项目提速；把任何报错都叫瓶颈。
**完成检查**：能解释为什么是这一处限制整体，以及修复后整体指标是否真的改变吗？
**相关条目**：[R01](#r01)、[R14](#r14)、[R33](#r33)。

<a id="r19"></a>

### R19 交接

类别：过程与变化。检索词：传给、接手、进入下一环节。

**关系含义**：对象、信息或责任由一方进入另一方的处理范围；发送、接收、理解和确认是不同状态。
**何时查阅**：说明部门、软件或人机之间怎样接续；展示交付为何不能止于生成文件。
**必须保留**：交接前后对象身份和关键字段可追踪；确认动作有明确责任方和可见反馈。
**视觉候选（重新设计后采用）**：

- 用同一条业务记录追踪导出、传送、校验和接收确认，每步留下对应状态。
- 在真实现场或流程图中显示交出方与接手方关注的不同内容，让验收发生在接手端。

**容易误用**：文件飞到屏幕外就算交付完成；生成成功直接变成客户可用；交接过程中悄悄换对象。
**完成检查**：观众能分清现在是谁负责、交出了什么，以及对方是否已经成功接住吗？
**相关条目**：[R10](#r10)、[R13](#r13)、[R29](#r29)。

<a id="r20"></a>

### R20 反馈

类别：过程与变化。检索词：检查、修改、再试一次。

**关系含义**：行动结果被观察并与目标比较，差异引起针对性的调整，再通过重复条件检查变化。
**何时查阅**：复盘测试、纠错或迭代；解释人为什么仍需参与判断。
**必须保留**：错误、修改位置与复测结果一一对应；保留测试范围，单次通过不等于长期稳定。
**视觉候选（重新设计后采用）**：

- 用同一个测试样例显示失败位置，只改一个相关条件，再在可比条件下复测。
- 让检查结果回到对应决策点，保留前一版和修改依据，循环在有证据的结果处暂告一段落。

**容易误用**：只画循环箭头；错误自动消失而看不到修改；把每次迭代都编成戏剧性失败。
**完成检查**：观众能说出看到了什么反馈、据此改了哪里，以及复测实际证明了什么吗？
**相关条目**：[R08](#r08)、[R33](#r33)、[R39](#r39)。

<a id="r21"></a>

### R21 筛选

类别：过程与变化。检索词：挑出、过滤、排除。

**关系含义**：依据明确条件，从候选总体中保留一部分并处理其余部分；选择规则决定留下什么。
**何时查阅**：解释异常检测、资料去重或候选选择；说明为什么不能把所有输出直接采用。
**必须保留**：规则、保留项、排除项和待复核项分开；算法筛选不被画成天然正确，保留误判与人工复核位置。
**视觉候选（重新设计后采用）**：

- 在真实候选记录中按当前规则逐项判定，保留来源，让边界样本进入待复核区。
- 在明确标为规则示意的空间中，让可追溯对象沿不同路径进入保留、排除和待复核区域；跟随一个边界样本说明判定条件。

**容易误用**：用漏斗让杂乱内容自动变成真相；把未选中的内容说成错误；删除后失去来源。
**完成检查**：观众能解释一项为什么留下、另一项为什么暂不采用，并看到规则的适用边界吗？
**相关条目**：[R28](#r28)、[R30](#r30)、[R37](#r37)。

<a id="r22"></a>

### R22 转换

类别：过程与变化。检索词：变成、识别、转换格式。

**关系含义**：同一内容在表示方式、结构或用途上发生变化；要说明哪些信息保留、丢失或需要补充。
**何时查阅**：讲图片转读数、资料转提纲、设计转页面；解释输入与输出之间的处理。
**必须保留**：输入与输出的对应可追溯；转换不等于内容自动正确，新增判断应另有依据。
**视觉候选（重新设计后采用）**：

- 保留原始图片中的局部区域，逐一对应识别字段，再显示不确定项的复核入口。
- 让本业务对象在受控空间内逐层显露其信息结构，原对象仍在，准确字段后期独立制作；只显示确有依据的对应关系。

**容易误用**：一团光变成完美结果；把格式变化说成知识增加；把初稿输出当成最终可交付物。
**完成检查**：观众能从输出回到输入，指出实际发生的转换与仍需检查的部分吗？
**相关条目**：[R19](#r19)、[R28](#r28)、[R32](#r32)。

<a id="r23"></a>

### R23 分支

类别：过程与变化。检索词：如果、否则、不同情况。

**关系含义**：同一起点因条件或选择不同进入不同路径；分支既可以是规则决定，也可以是人的取舍。
**何时查阅**：解释异常处理和适用条件；比较遇到不同情况应该怎样做。
**必须保留**：先显示判断条件，再进入路径；路径标签说明实际、备选或示意，避免把所有可能都画成发生过。
**视觉候选（重新设计后采用）**：

- 保留一条共同任务线，在真实判断点分开正常结果与需人工复核结果。
- 同一样例切换一个条件，展示操作路径如何变化，并保留原条件作比较。

**容易误用**：分支过多导致主线丢失；把概率分支画成二选一必然结果；没有条件就任意拐弯。
**完成检查**：观众知道分在哪里、依据什么，以及当前案例实际走了哪一条吗？
**相关条目**：[R12](#r12)、[R36](#r36)、[R38](#r38)。

<a id="r24"></a>

### R24 传播

类别：过程与变化。检索词：扩散、传递、影响更多。

**关系含义**：信息、状态或影响通过明确连接从起点到达其他对象；传播可能有延迟、衰减和中断。
**何时查阅**：解释通知、数据同步或系统影响范围；表现局部变化如何触及其他环节。
**必须保留**：连接代表实际通道或明示假设；到达、被读取、被执行三个结果分别处理。
**视觉候选（重新设计后采用）**：

- 从一个具体事件沿真实接收关系逐层展开，只点亮已经到达的节点，并保留未收到的部分。
- 在共享时间轴上显示同一更新在不同终端的到达时刻，说明延迟和失败重试。

**容易误用**：发光波扫过全图就代表全部成功；粒子无来源地乱飞；把消息送达当作行为改变。
**完成检查**：观众能追踪起点、通道、到达状态，以及影响没有覆盖到哪里吗？
**相关条目**：[R02](#r02)、[R14](#r14)、[R19](#r19)。

<a id="r25"></a>

### R25 整体与局部

类别：信息与观察。检索词：其中一步、整体、细节。

**关系含义**：一个对象或步骤属于更大的系统；放大局部用于理解细节，返回整体用于解释其作用。
**何时查阅**：技术细节需要与业务价值连接；某个部件或字段过小，无法在全景看清。
**必须保留**：局部在整体中的位置和身份保持可追踪；省略的部分不能被误当作不存在或已完成。
**视觉候选（重新设计后采用）**：

- 先建立真实流程全图，保留位置标记进入一处问题，解释完再返回同一整体。
- 实物外观与结构剖面并列对应，只揭示本次需要理解的部分，保留尺度和方向参照。

**容易误用**：放大后变成无关模型；一味穿越却不说明进入哪里；把一个局部方案说成解决整套业务。
**完成检查**：观众既能找到这一步，又能解释它对整体有什么影响吗？
**相关条目**：[R26](#r26)、[R27](#r27)、[R29](#r29)。

<a id="r26"></a>

### R26 尺度揭示

类别：信息与观察。检索词：不止一个、规模、原来这么多。

**关系含义**：观察范围扩大后，原先的个体成为群体或系统的一部分；新增视野改变观众对规模和位置的理解。
**何时查阅**：从一项工作转向同类工作的广泛存在；需要揭示个体背后的组织或空间。
**必须保留**：起始对象仍可被认领，尺度变化有连续参照；真实数量有证据；定性阵列不冒充统计样本。
**视觉候选（重新设计后采用）**：

- 从一个真实工作位置逐级展开到同类位置，保留最初对象与逐层新增的环境。
- 保持同一画幅中的起始对象不动，逐级揭示它所属层级的边界与有据数量；用归属关系扩展认知范围，不依靠相机拉远。

**容易误用**：单纯把整图缩小却没有新信息；复制大量对象暗示未经证实的规模；拉远后主体身份消失。
**完成检查**：每次扩大视野是否增加了必要信息，最后能否找回起点并说明它属于什么？
**相关条目**：[R02](#r02)、[R11](#r11)、[R25](#r25)。

<a id="r27"></a>

### R27 表象与背后

类别：信息与观察。检索词：背后、表面上、中间还有。

**关系含义**：已看见的结果或外观只呈现部分信息，改变观察位置或范围后才能看见支撑它的过程与条件。
**何时查阅**：从成功展示转向实施过程；解释一个答案为何还不等于事情办成。
**必须保留**：前后展示指向同一件事；隐藏部分有材料支持，不能为了反转虚构内幕或失败。
**视觉候选（重新设计后采用）**：

- 保留最终结果，在时间线上向前展开需求、修改、测试与交付记录，让结果找到过程依据。
- 从只见展示面的构图转到能同时看见操作与限制的位置，前景结果仍保持身份。

**容易误用**：每段都翻卡片或揭幕；把幕后一律画成阴谋；用复杂背景装饰冒充真实工作。
**完成检查**：新增信息是否真的解释了原先的表象，而非只是换了一幅更繁杂的画面？
**相关条目**：[R05](#r05)、[R25](#r25)、[R40](#r40)。

<a id="r28"></a>

### R28 来源与核验

类别：信息与观察。检索词：出处、证据、核对。

**关系含义**：结论需要回到能够支持它的材料，并检查时间、上下文与适用范围；链接存在不等于论证已经成立。
**何时查阅**：展示资料整理、事实检查或数据验证；将公开案例与本项目推演区分。
**必须保留**：来源与对应主张一一关联，必要上下文保留；识别出的候选、已核实事实和个人判断分别呈现。
**视觉候选（重新设计后采用）**：

- 从一句具体结论定位到原始段落或数据行，圈出真正支持该主张的部分并检查日期。
- 并列两份材料中同一字段，先解释口径，再标出一致、冲突和仍待确认的位置。

**容易误用**：用大量链接制造可信感；自动打勾代表核验；生成的屏幕、单据或现场充当真实证据。
**完成检查**：观众能回到支持该结论的材料，并区分证据本身与作者的解释吗？
**相关条目**：[R21](#r21)、[R29](#r29)、[R38](#r38)。

<a id="r29"></a>

### R29 身份对应

类别：信息与观察。检索词：同一对象、匹配、对不上号。

**关系含义**：同一对象在不同状态、表格或系统中保持身份，或者多个候选之间需要确定正确对应。
**何时查阅**：解释跨表核对、重复记录或用户匹配；连续镜头必须让观众知道仍是同一件事。
**必须保留**：稳定标识随对象保留，名称相同不代表身份相同；有歧义时保留候选，不擅自合并。
**视觉候选（重新设计后采用）**：

- 把同一业务编号贯穿原单据、识别结果与系统记录，逐字段核对对应。
- 同时保留同名对象的不同标识，显示一次错误匹配及正确判别依据。

**容易误用**：依赖颜色就认定是同一人；动效中内容悄悄替换；去重时删掉真实不同对象。
**完成检查**：转场或处理前后能否确认对象身份，遇到同名或缺标识时是否显示不确定性？
**相关条目**：[R19](#r19)、[R25](#r25)、[R28](#r28)。

<a id="r30"></a>

### R30 分类

类别：信息与观察。检索词：整理、归类、杂乱到有序。

**关系含义**：按照明确维度重新组织对象，使相似、差异和后续使用方式更容易识别；分类会改变可见关系。
**何时查阅**：资料多但难以使用；需要解释按什么标准组织工作。
**必须保留**：分类标准先明确，交叉与未分类项有去处；整理改变位置和归属，不自动提高内容真实性。
**视觉候选（重新设计后采用）**：

- 保留本业务对象的身份与来源，在连续空间中按用途分区；对象沿可追踪的路径进入对应区域，交叉或未定对象仍留有位置。
- 让同一批内容分别按时间与问题分类，对照两种结构适合回答的不同问题。

**容易误用**：东西自动飞进彩色格子便称学会了；分类标准中途改变；整理后来源和数量丢失。
**完成检查**：观众能说出分类依据，找回一项原资料，并知道分类后具体方便了哪一步吗？
**相关条目**：[R07](#r07)、[R21](#r21)、[R32](#r32)。

<a id="r31"></a>

### R31 视角选择

类别：信息与观察。检索词：从谁来看、重点、怎样理解。

**关系含义**：同一事实在不同问题或主体的观察下呈现不同重点；改变视角应保留事实，说明选择了什么。
**何时查阅**：解释判断角度、选题角度或需求差异；从工具展示转向实际使用者的处境。
**必须保留**：事实对象和背景不因观点需要而改写；突出局部时保留足以避免误解的上下文。
**视觉候选（重新设计后采用）**：

- 同一项目材料先按开发者功能展示，再按使用者任务检视，保留相同事实并改变关注顺序。
- 从设备正面切到实际操作者位置，显示此前被遮住的操作限制。

**容易误用**：换一个镜头角度就称改变观点；裁掉反例以强化结论；把所有视角画成同样可靠。
**完成检查**：观众能说出新的观察问题是什么、增加了哪条理解，而不只是看到取景变化吗？
**相关条目**：[R25](#r25)、[R27](#r27)、[R39](#r39)。

<a id="r32"></a>

### R32 重组

类别：信息与观察。检索词：重新组织、搭起来、调整结构。

**关系含义**：保留基本内容或部件，改变其组织方式、连接关系或呈现顺序，以服务新的任务。
**何时查阅**：资料变成提纲、零散步骤变成流程；解释人的选择如何影响最终表达。
**必须保留**：可追踪哪些内容保留、移除、合并或新增；结构变化不自动证明逻辑更好，新增连接需要理由。
**视觉候选（重新设计后采用）**：

- 以同一批有来源的材料构成两种提纲，突出为了回答当前问题而改变的主次和连接。
- 在真实流程图中移动一个环节并保留原位置痕迹，展示上下游影响和检查结果。

**容易误用**：让碎片自动聚成完美答案；仅交换卡片位置却没有意义变化；合并后丢掉冲突信息。
**完成检查**：观众能指出谁作出了什么组织决定，以及该决定如何服务当前任务吗？
**相关条目**：[R17](#r17)、[R22](#r22)、[R30](#r30)。

<a id="r33"></a>

### R33 可比对照

类别：证据与判断。检索词：前后对比、两种方案、有没有改善。

**关系含义**：在口径一致或差异已说明的条件下比较对象，让差异能在同一参照下理解；可比本身不证明因果。
**何时查阅**：比较方案、版本或操作前后；用画面支持效率、质量或可用性判断。
**必须保留**：固定单位、任务范围、样本和时间口径；未控制的差异要说明，不能把所有变化归给单一因素。
**视觉候选（重新设计后采用）**：

- 保留同一输入与验收标准，并排展示两次处理过程及结果，差异只在对应位置强调。
- 采用同尺度图形呈现指标，同时显示任务内容或测试条件，避免只比较漂亮的终态。

**容易误用**：新旧方案分别选最有利样本；换比例尺制造反差；把初稿与最终交付耗时直接相比。
**完成检查**：观众不用回忆或猜测口径，就能看出比较了什么、哪些条件相同、结论覆盖哪里吗？
**相关条目**：[R20](#r20)、[R34](#r34)、[R35](#r35)。

<a id="r34"></a>

### R34 数量与趋势

类别：证据与判断。检索词：增长、减少、多少。

**关系含义**：数量在对象间或时间上存在变化；先确定总量、比例、速率或累计值，再选择相应的视觉尺度。
**何时查阅**：口播有可靠数字或明确趋势；数量差异是理解结论所必需的信息。
**必须保留**：单位、基准、时间跨度和来源可见；定性趋势与实测序列区分，缺失值不补成平滑曲线。
**视觉候选（重新设计后采用）**：

- 用同起点同尺度的长度比较可比数量，把准确数值放在稳定信息层。
- 将真实时间序列与关键事件并列，显示波动、缺口和取样范围，而非只保留上涨片段。

**容易误用**：面积或体积比例冒充长度比例；截断坐标轴夸大差距；没有数据却绘制精确走势。
**完成检查**：图形变化是否对应真实数值，观众能否分清增长量、增长率和累计结果？
**相关条目**：[R02](#r02)、[R15](#r15)、[R33](#r33)。

<a id="r35"></a>

### R35 成本与收益

类别：证据与判断。检索词：值不值得、投入、节省。

**关系含义**：为获得某种结果，需要承担时间、金钱、维护或机会成本；价值判断取决于范围、条件和替代方案。
**何时查阅**：判断改造是否值得做；解释效率提升为何不等于利润或稳定收入。
**必须保留**：一次投入与持续成本分开，收益使用可验证口径；省下的时间不自动折算成现金，项目金额不等于利润。
**视觉候选（重新设计后采用）**：

- 并列现有做法和改造方案的工作阶段，显示减少了哪些步骤，又增加了哪些维护或复核。
- 在同一时间范围内分开展示投入与可验证产出，对尚未取得的数据保留空项或条件。

**容易误用**：只画一次购买费用却省略维护；把任何提速都画成收入上涨；用示意数字假装商业验证。
**完成检查**：观众知道为谁节省了什么、付出了什么，以及哪些收益仍有待验证吗？
**相关条目**：[R15](#r15)、[R16](#r16)、[R37](#r37)。

<a id="r36"></a>

### R36 阈值

类别：证据与判断。检索词：达到才、超过、最低要求。

**关系含义**：某个状态跨过明确条件后，处理方式或判定发生改变；阈值可能来自规则，也可能来自物理或统计限制。
**何时查阅**：解释告警、验收线、置信度或准入条件；说明为什么接近目标仍不算满足要求。
**必须保留**：阈值来源和单位明确，边界值如何处理可解释；人为规则不能被画成自然定律，单一阈值不能代表整体质量。
**视觉候选（重新设计后采用）**：

- 在稳定刻度上标明判定边界，显示同一对象跨界前后的状态和实际处理差异。
- 用相邻的两个测试样例对照，保留仅有的条件差异，解释为何进入不同分支。

**容易误用**：为了动画随意设数值；到线就全系统成功；忽略噪声、回滞或边界复核需求。
**完成检查**：观众知道这条线由谁或什么决定，跨过它具体改变哪一项判定吗？
**相关条目**：[R03](#r03)、[R12](#r12)、[R23](#r23)。

<a id="r37"></a>

### R37 取舍

类别：证据与判断。检索词：选择、代价、适合谁。

**关系含义**：在资源和条件限制下，方案对不同目标有不同表现，选择意味着接受某些代价或放弃部分收益。
**何时查阅**：方案没有全面胜出者；需要说明为何本项目选此方案而非另一个。
**必须保留**：目标、约束和优先级先明确；保留被放弃方案的真实优点，结论限定到当前条件。
**视觉候选（重新设计后采用）**：

- 同一任务下并列方案在精度、投入、维护等相关维度的表现，逐项回应实际约束。
- 展示一个真实选择点，保留另一条可行路径及其代价，让选择理由落在业务条件上。

**容易误用**：一边全绿一边全红来制造答案；把更贵等同更好；用天平动作替代具体评价依据。
**完成检查**：观众能说清选中了什么、接受了什么代价，以及条件变化后结论是否可能改变吗？
**相关条目**：[R09](#r09)、[R21](#r21)、[R35](#r35)。

<a id="r38"></a>

### R38 风险与不确定结果

类别：证据与判断。检索词：可能出错、风险、尚未保证。

**关系含义**：行动可能产生不同后果，发生条件、概率和影响未必都已知；风险表达应指出具体失败方式与应对。
**何时查阅**：解释系统限制、异常情况或部署前提；提醒一次成功不能证明所有场景稳定。
**必须保留**：已发生错误、可能风险和未知概率分开；概率数字有依据，严重程度不靠恐怖画面代替说明。
**视觉候选（重新设计后采用）**：

- 正常流程中标出一个实际可发生的异常入口，展示检测、暂停和人工处理的位置。
- 对照已验证条件与未覆盖条件，明确哪些情况下还需测试，而不把空白区域画成失败。

**容易误用**：任何风险都配红色警报和爆炸；把小样本成功率当普遍保证；用免责声明代替解释。
**完成检查**：观众知道可能哪里出错、造成什么影响、怎样发现和处理，以及还有什么未知吗？
**相关条目**：[R06](#r06)、[R23](#r23)、[R28](#r28)。

<a id="r39"></a>

### R39 经验形成判断

类别：证据与判断。检索词：熟悉业务、知道哪里错、人的判断。

**关系含义**：主体凭具体经历、领域条件和结果标准，对同样的信息作出有依据的选择；经验通过判断过程体现。
**何时查阅**：说明普通人的工作经验为什么有价值；解释人机协作中仍需人决定的部分。
**必须保留**：判断对应具体线索和后果，而非身份标签；个人经验有适用范围，不能替代缺失证据或专业验证。
**视觉候选（重新设计后采用）**：

- 让业务人员发现一个工具未识别的异常，保留发现线索、选择与后续检查。
- 同一候选输出旁显示实际业务条件，逐项采用、修改或退回，并说明每次决定的依据。

**容易误用**：用手搬动纸片就代表判断；给人头加灯泡便称经验；把所有人类决定都画成正确。
**完成检查**：观众能指出人的哪条经验改变了哪个选择，并看到判断如何接受结果检验吗？
**相关条目**：[R08](#r08)、[R20](#r20)、[R31](#r31)。

<a id="r40"></a>

### R40 累积到完成

类别：证据与判断。检索词：做成、交付、逐步完成。

**关系含义**：多个已验证的局部结果逐步满足整体目标；完成由明确验收条件定义，而不是由动画收拢或任务数量决定。
**何时查阅**：总结从初步答案到可用结果的过程；区分原型、测试通过、交付和长期运行。
**必须保留**：每项完成对应证据，未完成项继续可见；局部完成、一次测试与整体持续可用分别标记。
**视觉候选（重新设计后采用）**：

- 回到开头的业务任务，将已经验证的结果放回对应需求，剩余缺口仍保留。
- 沿真实项目时间线汇总选择、修改和验收记录，最后停在本次确实达到的状态。

**容易误用**：拼图合拢就宣布项目成功；用研究条目数量替代成片质量；删去占位镜头或待验证环节。
**完成检查**：观众能分清已证明完成的部分、仍在继续的部分，以及最后判定依据是什么吗？
**相关条目**：[R02](#r02)、[R16](#r16)、[R27](#r27)。
