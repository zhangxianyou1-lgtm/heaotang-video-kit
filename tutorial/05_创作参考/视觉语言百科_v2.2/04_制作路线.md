## 04 制作路线：表达目的确定以后再选工具

本章 T01–T05 是实现路线，不能与第 02 章 R 关系混用。路线名称不代表原作者实际使用的软件，也不保证当前环境已安装、可调用、价格合适或能达到目标质量。实际制作时核实能力和授权；本册不固定产品版本、价格和生成额度。

<a id="t01"></a>

### T01 真实素材与实际录屏

**选用条件：**画面承担亲历、项目结果、现场限制、真实操作或实验依据。先确认材料支持哪一个主张，再安排取景和强调。

**设计要求：**保留对象身份、时间、输入与必要上下文；敏感信息按实际授权处理。解释层可以叠加，但不得借裁切或拼接改变结果含义。没有真材料就标明缺口，改为说明、演示或推演，不生成假现场填补证据。

**检查与替代：**核对来源、完整性和可读性。录屏要能看清实际操作和反馈。缺资料时可以先交付分镜或示意段，明确其性质；不得据此宣布真实项目成功。

<a id="t02"></a>

### T02 受控二维图解与信息合成

**选用条件：**文字、数值、比例、节点、分类、时间线、流程或界面状态必须准确；视觉价值主要来自信息关系而非新的空间视角。

**设计要求：**稳定参照，对象先建立、关系再出现；标签靠近对象，数值带单位和范围。使用合成软件、二维动画、SVG、Canvas 或其他可控方式均可，不以代码量或动效数量衡量完成度。简单图解可以静止。

**检查与替代：**正常观看能读完且复述关系；对照口径、比例和单位正确。需要精确空间接触的部分单独转交 T01/T04。二维解释不应被强行包装成无业务依据的科技界面。

<a id="t03"></a>

### T03 高质量静帧与分层运动

**选用条件：**环境、情绪、尺度或关系隐喻的核心主要由一张构图承担；有限取景变化、分层视差或局部动态已经足以引导注意、交代空间或强化感受。静帧本身可以很有表现力，不必为证明“做了视频”额外制造大动作；但如果意义依赖完整场景持续变化，也不能只用整图推近冒充所需事件。

**先区分四种实现：**

- **静帧运镜：**对已有图像做有限裁切、缩放或位移，改变观看重点；图中对象没有因此发生真实姿态变化，也没有自动获得新侧面。构图和分辨率要容纳最终取景。
- **2.5D 分层：**把前景、主体、背景等拆层，设定相对深度、位移与遮挡，产生有限视差。先补足移开前景后会露出的区域；不能把几张平面当作完整几何任意绕视。
- **局部动态合成：**保留主要构图，单独制作或叠加必要的光影变化、局部物件动作、环境活动或信息层。各动态层要有来源与职责；若其中某层由生成视频取得，该层记为 T05，不能把混合镜头笼统记作静图动画。
- **图生视频：**把静帧作为参考，由生成工具产生后续时间变化，属于 T05。它可能涉及新姿态、环境变化或视点移动，必须检查生成后的实际结果；一张好图不能保证它会稳定地动起来。

**设计思考顺序：**

1. **稿意：**这一段要建立什么处境、情绪、尺度或判断？画面承担示意还是证据？
2. **场面：**从本稿独立设计对象、环境和相互关系，再选择需要借鉴的技法，不先找一张漂亮图替代含义。
3. **构图：**一张画面已经能交代什么？确定主体、前中后景、材质、光向和最终阅读位置；必要信息不能只靠日后运动补救。
4. **运动：**移动或变化要新增什么理解？若只需把注意力带到局部，用静帧运镜；若需有限前后关系，用分层；若需完整动态事件，转向 T05 或 T04。
5. **关键帧确认：**先看实际图像，检查主体、空间、质感及语义；有关键结果状态时也要确认其构图。静帧可来自真实素材、可用资产或生成画面，来源性质分别记录，中文和精确信息独立制作。
6. **短段验证：**按预定相机与局部动作制作一小段，实际查看边缘、遮挡、视差、信息阅读与情绪是否成立；转图生视频时，另检查生成对身份和场面的改动。

先确认构图再尝试动态，可以减少把错误场面反复送入视频生成的尝试；部分只需有限运动的镜头也可以直接用合成完成。这是可选择的制作策略，不保证一定更便宜或减少固定次数；成本按当前工具、实际尝试和用户预算核实，不据此推断别人的制作动机。

**检查与替代：**运动不露空洞、不把平面拉成伪几何；遮挡与视差合理，主体身份稳定。需要未准备的新侧面或大动作时，先判断精度：真实结构、机械接触或精确位置必须可复现的，选 T04 或真实拍摄；主要表现情境、感受或视觉隐喻且允许受检验的变化时，可优先试 T05。也可硬切到另一张已准备视点，但必须保留本段的解释目标。不得虚构真实结构，也不能因静帧好看就宣布动态通过。

<a id="t04"></a>

### T04 受控三维与结构动画（如 Blender）

**选用条件：**理解重点是必须精确稳定的几何、接触、遮挡或空间路径，并且需要可重复控制时，优先 T04。例如连续新视角中的正确结构、机械接触、真实厚度、内部剖层、指定视轴的反射或多个镜头中的稳定总成。出现运镜、空间变化或写实物件，并不自动要求 T04；不承担精确结构解释的动态情境也可评估 T05。

**设计要求：**先确认真实结构或明确的示意结构，准备符合最终近景要求的资产、材质与灯光。再验证关键姿态、接触、支点、镜头路径；贴在表面的文字须跟随透视和遮挡。风格化简化可以成立，但造型与光照要有统一设计。

**检查与替代：**首、中、尾和关键事件保持对象身份，硬物不随意变形，接触反应符合所表达的结构。检查最终画面，不因渲染器名或输出成功自动放行。资产不合格而空间要求可省略时，改用 T03/T02；空间关系不可省略时补资产或缩小范围，不能用粗糙模型冒充高完成度写实。

<a id="t05"></a>

### T05 生成视频与高质感动态场面（如即梦）

在 V1 已保存、当前镜头已选定表达方法后，可按需查 [08 视频生成提示词卡](08_视频生成提示词卡.md)。卡片帮助组织制图、运动与后期要求，实测状态按卡片记录；不是模型功能或效果保证。

**选用条件：**高质感情境、夸张尺度、超现实视觉隐喻、虚构情境中的表演性镜头、不要求工程精确的空间变化，以及自然环境、气氛和有机动作。它可以承担主镜头和叙事事件，不限于微风、云雾等轻微补充。是否适合由本镜的语义要求、必要稳定条件和短样片决定，不把“允许夸张”理解成可以任意改变对象或结果。

**条件性的生成优先尝试：**当意义依赖完整场景的材质、光影、动态和观看尺度，不要求精确工程结构或真实事件证明，而现有三维资产又不足以达到所需画面质量时，优先测试“关键帧确认 → 生成短段”。这能让执行者直接验证所需的场面表现力，避免把原本依赖场景与情绪的镜头降成粗糙模型或解释卡片。关键帧可以沿用 T03 的构图流程；若当前工具不支持参考图等方式，就按已核实能力另选测试方法。

生成优先指优先验证这条路线，不是保证成功、每镜必用、只准即梦或禁止 Blender。资产充分、控制要求高时仍可选择 T04；一张构图和有限运动已经足够时可停在 T03；真实现场能更好承担任务时选 T01。不给博主绑定软件，不给生成镜头设固定次数或占比。

**设计要求：**明确主体、环境、动作起止、相机、结果状态，以及哪些变化是设计需要、哪些身份与数量必须不变。视觉隐喻也要保留原句的关系与限制，不能用巨大破坏或剧烈形变替代所有意思。先检验关键帧是否已经传达该场面，再选最容易失败的运动或转变做短段；确认可用后扩展。可以尝试参考图或首尾状态等当前工具支持的控制手段，不假定参数、输出规格或费用必然可用。

有重要中文、数字、标识或图表时，优先把该信息层交给 T02 后期合成；它们无需与动态底图一起生成。必须附着在运动表面时另查跟踪、透视和遮挡，精确受控表面可交给 T04。既不因有字就取消整镜生成，也不接受失真的字作为完成结果。

**检查与替代：**实际查看短段，核对主体身份、必要形状与数量、接触、重心、方向、空间路径和最终状态；有意设计的超现实变化与意外漂移分别判定。相机进入暗处、遮挡物或新空间时，检查入口、方向与落点是否可辨，不能只靠黑场掩盖断裂。还要检查场面是否达到需要的材质、光照与情绪表现，技术上生成成功不等于画面达标。

T05 不替代真实事件、项目结果或历史现场的证据，也不替代必须精确复现的机械、科学机制和真实操作。生成的重建、推演和隐喻应让人识别其性质。若短段不能稳定满足必要条件，先减少同时动作、改起止状态、拆镜或换 T03；精确关系改 T04，事实证据回到 T01。改路线要保留观看目标，不能把未实现的大场面偷偷换成无关的简单动画。

### 04.1 按图层选择而非给整镜贴一个软件名

| 图层需要 | 可选路线 | 接合时必须检查 |
|---|---|---|
| 真实证据 | T01 | 来源、语境、事实范围 |
| 由构图承担的环境、情绪或尺度 | T01/T03；只有动态确有作用时加入 T05 | 构图、材质、有限视差、露出区域与来源性质 |
| 依赖整体动态的高质感情境、表演或超现实隐喻 | T05 可优先测试；按资产与控制需要也可用 T01/T04 | 语义关系、主体稳定、动作起止、空间路径、材质光影与示意身份 |
| 局部动态或环境活动 | 受控合成；生成的活动层记 T05 | 与底图的光向、透视、遮挡、触发时刻及运动接合 |
| 必须精确稳定的机械或空间主体 | T01/T04 | 几何、轴心、接触、连续新视角与遮挡 |
| 中文、数字、图表、界面 | T02，或 T04 受控表面 | 字形、数据、跟踪、透视和阅读 |
| 字幕、标签、片名 | T02 | 主体遮挡、声画时机和目标屏幕 |

例如精确转动的设备可以由 T04 控制，旁边的数据由 T02 控制，环境来自 T03；高质感隐喻场面可以先由 T03 确认关键帧，再以 T05 生成动态，最后用 T02 加中文。前者重点是结构，后者重点是场面表现，不应因都出现空间运动就强行使用同一条路线。混合路线只有在各层的光线、透视、遮挡和时间能衔接时才成立。

### 04.2 先检查什么

| 最难的问题 | 第一个应验证的东西 |
|---|---|
| 资产廉价或画面没有重点 | 最终观看尺寸下的关键静帧 |
| 静帧很好看，但运动不知道增加什么 | 先写运动新增的理解，再看有限运动短段；没有必要就保留静止 |
| 分层后露洞、拉伸或空间失真 | 最大位移处的补背景、遮挡边缘与前后景相对运动 |
| 精确接触与身份连续 | 接触前、接触时、结果状态及连续短段 |
| 图表容易误导 | 口径、数值、比例与可复述性 |
| 高质感情境或隐喻缺少合适三维资产 | 先验收场面关键帧，再测试生成短段的表现力；精确结构要求不能一并省略 |
| 生成的大动作、空间变化或有机运动容易漂移 | 最难动作的短样片，检查必要不变项、起止状态、路径与语义 |
| 真实结果没有证据 | 原始材料与主张范围 |
| 声画不同步 | 实际音轨、剪口和导出后的连续播放 |

将最难的问题提前解决，再做批量镜头。把同一错误复制到几十个镜头不算推进质量。

### 04.3 避免把工具习惯变成导演规则

风格名不对应固定软件；写实不必一定三维；解释不必一定二维；发光或液体不必一定生成视频。每镜不必运动，主体不必永远占固定百分比，结果停留不必统一秒数。时长由内容难度、正式音轨和实际观看决定。

工具限制可以要求改镜头，但应保留观看目标并说明代价。不能为了继续用熟悉的模板，把处境与情绪都改成卡片流程图，或把数据比较都改成实体碰撞。
