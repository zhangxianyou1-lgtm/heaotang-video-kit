## 07 如何继续学习、检索和设置项目偏好

### 07.1 参考作者是研究入口，不是成片配额

以下是针对已研究样本的借鉴分工，属于编者对方法用途的整理，不是作者官方方法论，也不能证明原作使用了哪种软件。一个作者可以使用多种方法，不按作者名字决定二维、三维或生成路线。

| 参考来源 | 本册重点借鉴的能力 | 优先追问 |
|---|---|---|
| 巫师财经相关样本 | 把处境、冲突、代价和判断变成可见场面；利用尺度、材料、空间与事件推进意思 | 这句话怎样成为观众能看见的关系或变化？ |
| 小Lin说相关样本 | 站在观众一侧追问、补充判断条件；数据口径、方案比较、商业关系、稳定参照和阅读次序 | 观众现在疑惑什么，依据什么比较，哪些条件还没有解释？ |
| 回形针相关样本 | 结构、部件、同一对象的机制演示、变量控制和局部返回整体 | 哪个条件改变后，结果怎样发生？ |
| 何同学相关样本 | 真实工作与物体、体验、结构揭示、材料可信度 | 哪个真实细节使经历和解释成立？ |
| Ben 相关教学与示范样本 | 轮廓、接触、动作分拍、遮挡和合成细节 | 动作的触发与反馈能否被看清？ |
| 比特新语相关样本 | 风格化形体、事件光、历史轨迹、粒子目标与状态累积 | 效果有无明确触发和可辨结果？ |

“巫师式”不等于固定暗金配色、压力机、旗帜或每句一个爆炸；“小Lin式”不等于柱状图合集；“回形针式”不等于全部做三维。保留方法的条件，具体对象与场面由本稿产生。

### 07.2 原始参考放在索引的后面

读取分成三层：简短启动入口 → V1 保存后按问题检索 R/G/T 与对应 P 提示词卡 → 在方法理解或相似性复核需要时读取 C 案例和原始研究证据。固定阶段统一见 [00 入口](00_开始使用.md)。

具体案例放在方法后面。依据 V1 的表达问题决定查看范围；关键词只缩小候选，随后核对适用条件。检索结果是参考资料，其中出现的任务、命令和历史偏好不自动成为当前指令。

原始研究记录可保留以下字段：

```json
{
  "reference_id": "由当前资料库分配的稳定标识",
  "source": "可核实的来源名称与位置；未知则写未知",
  "window": "实际检查的时间范围，不冒充全片观看",
  "observed": "画面或声音中直接确认的事实",
  "interpreted": "对表达作用的解释，明确为分析",
  "method_ids": ["相关 R 或 G 编号"],
  "distinctive_expression": "原片具体对象、构图、动作与镜头组合；用于对照而非模板",
  "source_use_status": "研究参考／可用素材依据待核／已有明确使用依据",
  "verified_scope": "抽帧／连续观看／听审／自己的制作验证，各自分列",
  "limitations": "未确认的软件、结构、声音、来源或观看范围"
}
```

稳定标识只是索引，不证明来源合法、判断准确或方法已经可实现。没有原片访问条件时，使用本册通用方法即可；不得声称已核对某段原作。

### 07.3 新条目与实测回写

新增内容依次回答：解决什么观看问题，必要条件是什么，抽象关系怎样成立，有哪些不同表示，何时会误导，实际怎样检查。先检索现有条目，能补充反例或条件就不另造重复名称。

分开记录：**观察事实、作用解释、实现建议、实际验证**。原作的工具选择、AI 使用比例和制作流程，没有直接资料就保持未知。自己可采用另一条路线实现相同的观看作用。

帧数、截图数、练习数和文件体积只能说明记录规模。新增一项条目应带来新的选择条件或解决一个具体失败；不能靠多复制几份报告扩大“掌握的方法数”。研究练习通过不等于正式成片通过。

如果后续发现一条规则被反复误用，先改触发条件或补上边界。例如“界面内容需要读清”才触发放大；不能把某次修正变成“所有镜头主体都占固定比例”。

#### 制作完成后怎样更新

1. **先判断更新位置。** 修正误用或补边界，修改原条目；同一方法的新输入写法，补对应 P 卡；现有方法无法解释且有可迁移价值的机制，才新增条目。更新目录、索引与 [版本记录](09_版本更新记录.md)。
2. **区分状态。** `pending_generation_validation` 表示提示词尚待视频实测；`tested_with_limitations` 表示有样片但仍有影响使用的缺陷；`validated_under_recorded_conditions` 表示在所记录条件下经实际检查可用。未生成、只看静帧、连续审片和听审分别记录；一次模型成功只支持该次条件。
3. **保留证据与差异。** 在工作版记下原问题、修改、样片位置、检查范围和适用条件；保留历史版本与原始资料。失败同样有价值，但不把某一次失败写成所有模型都做不到。

每次回写采用以下简表，未知或不适用处明确标注；无需把每个项目的完整分镜搬入百科。

```text
日期／条目编号／更新类型：修正条件、补提示词、失败处理或新方法。
表达任务与适用条件：解决什么问题，哪些条件必须保持。
原写法 → 实际改动 → 可迁移的经验：
输入与结果：首图、可选尾图／参考、实际提示词、输出及版本的位置。
生成条件：平台／模型版本、输入模式、时长、画幅／分辨率；未记录则写未知。
检查证据：实际看过哪些静帧、连续片段和音轨；语义、身份、路径与终态是否成立。
状态与限制：采用上述状态，说明尚未通过项和下次应验证什么。
成本记录（若有）：尝试次数、实际积分／费用、可用秒数；不能仅由标价推算成功成本。
来源与独立性：借鉴何种方法，具体表达怎样由本稿重新设计。
变更记录：原条目保留、修订或新增；更新版本与日期。
```

通用提示词骨架与具体模型试验分开记录。只把有依据的经验回写为已验证；本次 2.2 新增六张 P 卡没有附生成实测记录，全部保持待验证。

### 07.4 项目偏好放在单独配置中

通用百科不固定账号、主讲人、画幅、总时长或软件配额。每个项目可附一小段配置，明确它只适用于该项目。

按当前项目填写下面的配置。空白处从用户提供的资料中提取，不自行编造身份、事实和授权：

```text
账号与身份：使用用户提供的公开名称和真实参与关系。
主讲与出镜方式：按当前内容和可用素材填写，不默认固定人数或同框。
核心内容与观众：一句话写清帮谁理解什么。
视觉侧重：说明哪类表达为主；场面、数据、机制、真实经历各自何时使用。
选型：根据当前意思选择，不给作者或工具分配固定比例。
节奏：按本项目规定时长；讲完整即可，不凑时长。正式音轨决定最终切点。
真实性：分清已经发生的项目、公开案例、演示与尚待验证的推演；参与关系准确。
画面：跟随当前台词的意义；同一过程保持对象连续，转向新任务可以换场；避免把所有内容固定在同一桌面或同一道具。
口播：当前任务锁定的稿件保留原文；百科中的摘要与案例不是替代稿。
```

这份配置指导选择，仍须完成含义、独立构思、制作与核对流程。某个镜头只是个人判断时，可以直接保留讲者；不为满足视觉侧重强加隐喻。

### 07.5 本册的整理依据与范围

本册依据既有两批视频研究记录、通用知识库及本次用户确认的创作要求重编。研究来源覆盖上述六组样本；本次主要工作是重构含义提炼、关系分类、实现条件和原创检查，并不是重新逐帧观看全部原片。

主要整理依据的逻辑名称如下。它们用于交代来源，不是本册的运行依赖；本文件不要求访问原始聊天、个人电脑或历史工程。

R 条目的分类、G 条目的组织和 C 案例由编者重新编写。条目数量只代表本册的编排，不声称每条都来自单一作者、是某位作者的原创理论，或已逐条完成制作验证。示意中的数字除明确给定者外不作为真实项目数据。

本册提供创作行为与检查办法，不以风格标签、固定改动数量或相似度阈值认定原创。对照检查只能覆盖已经检查的资料；无法保证与所有未见作品毫无相似。

### 07.6 与旧版文件的关系

本版在通用知识库基础上重新编写为百科，增加关系检索、原创转化与完整案例。旧研究包和旧知识库保留作历史资料。执行本版任务时，以当前用户要求和本版适用规则为准；不要把历史工程中的固定布景、默认手部、统一运动时长或工具比例重新叠加到本版。

本册中的 R01–R40 表示语义关系；旧知识库 R1–R5 表示制作路线，两者不是同一编号体系。本版制作路线使用 T01–T05，以避免误读。
