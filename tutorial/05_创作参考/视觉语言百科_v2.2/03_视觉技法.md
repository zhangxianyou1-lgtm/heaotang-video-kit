## 03 视觉语法与制作方法词典

本节用于把已形成的原创画面构思实现清楚。先完成台词含义、关系与观看任务的提炼，再按具体问题查阅；条目是可选择的方法，不是每镜必做的清单。参考中的具体场景、角色、道具与镜头组合不作为本片制作命令。

下列方法是研究后的编者整理，不声称某位作者全部采用过，也不证明原作者使用了某款软件。所有实现都需按实际素材与工具条件验证。

<a id="g01"></a>

### G01 焦点层级

**检索词**：注意力、主次、构图、观看顺序。

**何时查阅**：画面同时有主体、文字与背景，观众可能不知道先看哪里。

**视觉操作**：先决定本句唯一的主要关注点，再用位置、尺度、明暗、清晰度或运动差异建立层级。次要信息可以保留，但在轮到它之前降低显著程度；转移关注时同步改变相关层的主次。

**适用前提**：主要关注点来自当前台词的意义，不能由素材中最亮或最漂亮的物件代替。必要的上下文仍应可找到。

**实现方式**：实拍调整机位与光线；二维调整排布与对比；三维调整照明、遮挡和景深。信息清楚时可以保持静止。

**常见误用**：所有元素同亮同大同动；靠持续闪光抢注意；将有用背景全部模糊掉。

**检查方法**：缩到目标观看尺寸，确认第一眼落点与本句一致，并能按预期顺序找到第二项信息。

**关联关系**：R07、R25、R31。

<a id="g02"></a>

### G02 整体、局部与返回

**检索词**：全局、局部、定位、解释层级。

**何时查阅**：观众既要理解某个细节，又需要知道它在系统中的位置。

**视觉操作**：先建立整体和当前部位的对应，进入局部只解释必要关系，再回到整体显示该细节的作用。也可从局部开场，但随后要补足位置参照，避免观众把局部误认成全貌。

**适用前提**：局部与整体确实属于同一对象；内部结构有资料依据。返回必须增加理解，不能只为完成固定流程。

**实现方式**：录屏裁切、二维局部放大、实拍切换景别或受控三维剖切均可；保留标签、轮廓或位置线索。

**常见误用**：放大后对象身份丢失；每次切入都换一套形状；用虚构内部结构填补资料空缺。

**检查方法**：让观察者指出细节原来在哪里、改变了什么，以及返回整体后影响的范围。

**关联关系**：R25、R29、R12。

<a id="g03"></a>

### G03 尺度揭示

**检索词**：推拉、规模、个体与群体、空间发现。

**何时查阅**：需要让观众发现个体之外的系统、数量范围或空间处境。

**视觉操作**：先设计揭示后的全貌，再选一个有辨识度的局部作为入口。扩大视野时逐步加入新的关系，保留起始对象的位置线索；揭示结束后让新增信息可以被辨认。

**适用前提**：尺度变化必须支持台词。若密集物体只是情绪示意，应避免把数量、排列或地域分布暗示成统计事实。

**实现方式**：实拍升降与拉远、二维多层展开、三维相机运动或有限静帧缩放均可，按实际素材能提供的空间选择。

**常见误用**：只把一张图缩小却没有新增意义；无限复制物件凑震撼；推拉过程中原对象无理由换位。

**检查方法**：比较起点和终点，说明观众新增知道的事情；检查空间方向与数量含义是否一致。

**关联关系**：R26、R02、R11、R27。

**生成提示词卡**：[P03 尺度揭示](08_视频生成提示词卡.md#p03)。

<a id="g04"></a>

### G04 空间阻挡与显露

**检索词**：遮挡、显露、门槛、隐藏信息。

**何时查阅**：台词涉及看不见、接近不了、表面背后或新的可达空间。

**视觉操作**：让遮挡物、被遮挡对象和观察位置先形成明确关系，再通过机位移动、遮挡物变化或条件改变显露信息。显露应改变观众的认识，入口、障碍和去向由本稿重新选择。

**适用前提**：物理阻挡、信息未知和心理门槛是不同含义；隐喻只能帮助理解，不能冒充实际障碍的技术解释。

**实现方式**：前景实物、受控遮罩、三维遮挡或分层合成均可。大幅绕视需要补齐背面和空间资产。

**常见误用**：为每种困难套一扇门；对象穿透遮挡物；尚未辨认障碍便直接切到成功。

**检查方法**：能指出原来遮住什么、哪项条件改变后看见什么，且变化没有加强原稿结论。

**关联关系**：R03、R06、R13、R27。

**生成提示词卡**：[P04 空间阻挡与显露](08_视频生成提示词卡.md#p04)。

<a id="g05"></a>

### G05 对象连续性

**检索词**：身份、连续、对应、稳定参照。

**何时查阅**：同一对象跨状态、跨机位或跨镜头承担连续解释。

**视觉操作**：先确定识别对象所需的特征，如编号、轮廓、位置或功能，再让必要特征贯穿变化。跟踪每个对象的来源、去向及状态；新增与替换对象要有可见交代。

**适用前提**：连续性服务于同一问题的理解。转向另一话题时可以换场，不为统一外观强迫所有内容共享同一个道具。

**实现方式**：真实素材保留来源时间；图形使用稳定对象标识；三维复用同一资产；生成素材逐段核对身份。历史轨迹留在场景坐标中。

**常见误用**：相同标签贴到不同对象；对象在切镜后变形或数量改变；旧轨迹跟着主体一起旋转。

**检查方法**：逐个回答它从哪来、现在在哪、是否仍是原来那个，以及何时发生了有依据的替换。

**关联关系**：R19、R20、R29、R40。

<a id="g06"></a>

### G06 因果动作与接触

**检索词**：接触、触发、受力、作用关系。

**何时查阅**：变化需要通过碰触、压缩、开启、传递或操作触发来解释。

**视觉操作**：确定作用对象、接触位置和触发时刻，再安排受作用对象的响应、主体的减速与余动。形变、碎屑、事件光和音效围绕同一个事件发生；先让关系成立，再添加强化效果。

**适用前提**：表现真实机制时遵循实际结构与作用条件；纯视觉隐喻保持内部一致，并让观众知道其示意性质。

**实现方式**：实拍适合真实操作；二维适合明确的简化关系；三维适合多视角接触与结构。分别处理硬件和软材料。

**常见误用**：未接触就触发结果；支点漂移；声音与碰撞错位；用晃动掩盖穿插或悬空。

**检查方法**：查接触前后关键帧的缝隙、遮挡和响应先后，再原速检查是否自然可辨。

**关联关系**：R01、R10、R12、R22。

<a id="g07"></a>

### G07 动作前建立与动作后理解

**检索词**：节拍、预备、余动、停留。

**何时查阅**：关键变化容易发生过快，或观众只能注意到动画而没有理解结果。

**视觉操作**：安排对象辨认、主要变化、次级反应和结果理解的先后。对象可在上一句提前建立，结果也可跨句保留；主动作、文字与相机不必同时启动或停止。

**适用前提**：这是注意力安排，不是每镜必须包含四段的模板。持续事件可以在动作中切出；阅读需要与正式音轨决定实际时长。

**实现方式**：先定关键状态与注意落点，再分配时间、速度和缓急。材料余动服从重量与柔软度，避免统一回弹。

**常见误用**：复制参考片固定帧数；所有层一起飞入；结果刚出现便转场；把整段加速当作删减。

**检查方法**：原速试看能复述变化及结果，读字幕时仍不会错过关键动作；抽帧检查不代替原速观看。

**关联关系**：R05、R17、R20、R40。

<a id="g08"></a>

### G08 同条件对照

**检索词**：前后、对照、变量、可比性。

**何时查阅**：要说明一个改变是否带来差异，或比较两个方案。

**视觉操作**：先锁定对象、输入、任务范围、单位与观察条件，再突出需要比较的变量。并排或顺序展示时保留共同参照，变化后仍能找回基线；必要时同时呈现未改善部分。

**适用前提**：真实测试需要实际记录；设计示意只说明比较方式。条件不能统一时，应明确差异，避免暗示因果已经被证明。

**实现方式**：可用同机位实拍、相同界面操作、共轴图表或受控三维试验，信息层沿用一致的视觉编码。

**常见误用**：把完整交付和初稿比较；换环境后归功于某个按钮；改变比例尺放大差异。

**检查方法**：逐项核对哪些条件相同、改变了什么、结果测到哪里，检查画面是否偷偷加强结论。

**关联关系**：R20、R33、R35、R38。

<a id="g09"></a>

### G09 数量、比例与时间

**检索词**：图表、单位、时间带、数据。

**何时查阅**：观众需要判断多少、占比、增减或耗时差异。

**视觉操作**：先明确指标和口径，再选择长度、位置、面积或重复单位等编码。共同基准先出现，比较项随后加入；数字、单位与来源保持可读，时间带使用同一开始和结束条件。

**适用前提**：区分实测、自述、估算、目标和纯示意。没有数值依据时采用定性表达，不能靠动画补出精确百分比。

**实现方式**：精确信息用受控二维图层或真实数据视图；空间背景可以独立制作。变更单位或轴范围时在画面中交代。

**常见误用**：用体积夸大一维差异；不同组各用比例尺；数字持续跳动无法阅读；把目标值画成成果。

**检查方法**：按数值反查图形比例、单位和范围，正常播放确认观众知道比较包含及不包含什么。

**关联关系**：R15、R33、R34、R35。

<a id="g10"></a>

### G10 流程、分支与例外

**检索词**：流程、条件、异常、反馈路径。

**何时查阅**：需要解释任务怎样推进，何时分流，失败后回到哪里。

**视觉操作**：先用最少节点展示一次正常路径，再在触发位置加入条件和例外。箭头表示具体传递或先后，节点保留当前状态；用一个可追踪实例走完整条路径。

**适用前提**：流程依据实际资料或明确的方案推演。区分处理、等待、人工判断和完成，复杂系统不必一次全部展开。

**实现方式**：二维流程、真实操作录屏或实物工序皆可。物理位置重要时加入空间视图，准确状态和文字仍受控。

**常见误用**：堆满箭头却没有触发条件；异常直接消失；数据经过一个框就自动变成正确结果。

**检查方法**：跟踪一个正常输入和一个异常输入，确认每次转移都有条件、下一步和明确的结束状态。

**关联关系**：R17、R18、R19、R20、R23。

<a id="g11"></a>

### G11 图解与真实证据结合

**检索词**：证据、标注、来源、示意。

**何时查阅**：真实材料信息复杂，或需要在记录上解释一个判断。

**视觉操作**：先确认素材支持的事实范围，再用裁切、指示、局部高亮或独立图解指出当前依据。保留足够的来源与上下文；由真实画面转入重建或推演时，明确表达状态改变。

**适用前提**：真实证据、公开案例、演示与设想各自标明。图解可以揭示关系，不能替材料补出不存在的结果。

**实现方式**：使用获准采用的实拍、录屏、单据或数据，解释层独立合成。必要的隐私处理不能改变结论所依赖的内容。

**常见误用**：裁掉限定条件；用生成画面冒充现场；把相邻两段素材剪成未经证实的因果。

**检查方法**：逐条对照主张、原材料和画面标注，确认他人能追溯依据，并识别哪些只是说明。

**关联关系**：R27、R28、R33、R39。

<a id="g12"></a>

### G12 图层分工与合成

**检索词**：分层、合成、文字层、遮挡。

**何时查阅**：同一镜头同时需要高质量环境、受控动作和准确文字或数据。

**视觉操作**：按职责拆分环境、主体、行为、文字、数值与声音，分别选择实现方式。先规定共同的镜头、透视、光向、遮挡及时间关系，再合成，明确哪个层负责每项必要信息。

**适用前提**：拆层应降低关键风险，而不是增加无意义复杂度。物体表面的文字要跟随透视和遮挡，画外标签则保持稳定阅读。

**实现方式**：真实背景、生成静帧、二维信息和受控三维可以组合；准备必要的遮罩、接触影与颜色匹配。

**常见误用**：字幕像贴在屏幕上却声称印在实物上；背景与主体光向矛盾；层间运动节奏不一致。

**检查方法**：逐层单看确认职责，再合看边缘、透视、接触、运动与阅读是否共同成立。

**关联关系**：R13、R14、R29、R32。

<a id="g13"></a>

### G13 材质、光线与接触影

**检索词**：质感、材料、光照、美术验收。

**何时查阅**：场景虽可辨认，却显得像廉价模型、平面贴纸或无法区分材料。

**视觉操作**：先建立轮廓、厚度、接缝和尺度，再处理表面、反射、透射、主光、暗面及接地关系。材质细节服从物体用途和使用状态，留出明暗层次，不靠装饰光掩盖形体。

**适用前提**：写实和风格化各有一致的美术目标；简化可以是设计选择，但应达到本次确定的品质目标。

**实现方式**：可改实拍布光、换优质资产、精修三维或采用高质量静帧。先检查关键静帧，再扩展动作。

**常见误用**：纸像厚泡沫；所有表面同样光滑；磨损随机撒满；用运动模糊遮住粗糙资产。

**检查方法**：关闭运动与装饰光，检查材料、尺度和接触仍可信；未达美术目标时先修或换路线。

**关联关系**：R01、R03、R08、R11。

<a id="g14"></a>

### G14 二维与三维取舍

**检索词**：二维、三维、空间需求、路线选择。

**何时查阅**：需要决定一段内容是否值得建立完整三维场景。

**视觉操作**：先列出必须看见的信息。数量关系和稳定标签可用二维；新侧面、厚度、内部结构或接触必须准确时，采用真实素材或受控三维。情境与隐喻需要空间变化而不承担精确结构证明时，可用 T05 短样片验证。

**适用前提**：三维不是高级感的保证，二维也不等于卡片讲解。已有资产、资料精度和最终画面效果共同决定选择。

**实现方式**：可以只把一个关键对象做成三维，保留二维数据层；不需要空间运动的环境可用真实或高质量静态素材。

**常见误用**：为准确数字建复杂立体装置；用贴片假装大幅绕视；因已打开某软件而降低画面目标。

**检查方法**：说明每个三维维度带来的必要信息；若取消它不损失理解，就重新评估成本与画面质量。

**关联关系**：R13、R22、R25、R33。

<a id="g15"></a>

### G15 静帧与有限视差

**检索词**：静帧、Ken Burns、2.5D、分层视差、局部动态合成、图生视频、最小可见变化。

**何时查阅**：一张构图已经能承载本稿关系，需要判断怎样使它有必要的动态，而不破坏原有品质。

**视觉操作**：先写清本稿意义，说明一张构图为何足以承担，再确定关键帧与运动任务。例如待办占满操作空间，可以小幅拉远显露占用范围，无须让纸张乱飞；是否运动由新增理解决定。

**适用前提**：保持主体身份，补齐分层后露出的遮挡区域；平面推拉与视差不超出图像已有空间。需要新视角或大变形时，精确结构转 T04，可容许变化的情境转 T05 试片。

**实现方式**：区分四种工艺：Ken Burns 只移动或缩放平面；2.5D 用层间相对运动；局部动态合成只改选定区域；图生视频生成新的时间状态。选择与流程详见 T03、T05。

**常见误用**：将四种工艺混称推拉；图层漏底、身份漂移；拉伸伪造背面；用运动数量代替画面质量。

**检查方法**：比较静帧与短动态，用足以看清且推进意思的最小变化验证运动价值；检查最大位移处的补绘、遮挡和文字。

**关联关系**：R04、R05、R25、R26、R27。

<a id="g16"></a>

### G16 生成画面的可控边界

**检索词**：生成视频、身份稳定、精确结果、混合路线。

**何时查阅**：考虑用生成素材表现高质感情境、超现实隐喻、环境、有机动作或难以直接取得的示意场景。

**视觉操作**：先写出起止状态、主体身份、主要动作及先后关系和必须保持的条件，再用短样本检查最难部分。把关键数字、文本、结构或精确结果安排到可验证的层，必要时更换路线。

**适用前提**：按实际可用工具核实能力，不推断参考作者的软件。生成画面不能作为客户成果、真实测试或亲历事件的证据。

**实现方式**：可以结合原创参考图、有限生成动作与受控合成；需要连续精确接触时考虑实拍或受控三维。

**常见误用**：文字漂移、物体改形、数量改变；反复抽取看似正确的单帧，忽略中间身份不稳定。

**检查方法**：检查全段主体、文字、数量、接触和终态；试验成功之前保留未验证状态。

**关联关系**：R22、R24、R29、R38。

<a id="g17"></a>

### G17 镜头转场与注意交接

**检索词**：转场、硬切、匹配、注意落点。

**何时查阅**：切换观察对象、语境或尺度时，观众可能失去方向。

**视觉操作**：先决定新镜头为什么出现，再选择直接硬切、位置匹配、运动匹配、遮挡或短叠化。需要连续感时保留一个明确共同点，新信息成立后再退出旧参照。

**适用前提**：共同点应服务于理解，不能只因轮廓相似便暗示两件事有实际关系。独特转场组合需从本稿重新设计。

**实现方式**：实拍剪接、二维遮罩、三维相机或合成都可；入口先被辨认，运动方向与切后落点相互照应。

**常见误用**：用长闪白掩盖所有切换；强行连续融形；每次转场重新打乱方向；吞掉结果阅读时间。

**检查方法**：查看切点前后并原速播放，确认视线有落点、语义有推进、没有新增错误因果。

**关联关系**：R17、R19、R26、R32。

<a id="g18"></a>

### G18 字幕、标签与阅读

**检索词**：字幕、标签、字号、可读性。

**何时查阅**：口播字幕、对象名称、证据原文和动画同时争夺观看时间。

**视觉操作**：区分字幕、名称和证据三种任务。字幕按语义分组，名称靠近对应对象，原文只突出当前依据。先安排必要阅读，再给装饰和次级运动分配空间与时间。

**适用前提**：以实际画幅、观看设备与播放器界面验证；原文、单位、数字和说话人来自材料，不能把固定像素数当普遍规则。

**实现方式**：文字独立计时和渲染；复杂资料可以局部放大或重排，但保留必要上下文。重要标签跟随对象而不频繁漂移。

**常见误用**：把口播又复制成满屏大字；整页资料缩到无法读；字幕盖住接触点或关键结果。

**检查方法**：按目标显示尺寸正常播放，无需暂停即可读完必要信息，且阅读不会使关键动作被错过。

**关联关系**：R07、R28、R29、R34。

<a id="g19"></a>

### G19 声音、节奏与真人

**检索词**：音轨、真人、小窗、同步。

**何时查阅**：需要让讲者、资料与动作围绕口播形成清楚的观看节奏。

**视觉操作**：按实际录音的句子、重音和停顿安排切点。人物承担亲历与态度时给表达空间，资料需要阅读时让其成为主体；音效对应可见事件，音乐不遮挡关键语言。

**适用前提**：临时声音只用于估时，不能当成正式对齐。小窗的表情或手势应有作用，不设置固定露脸比例。

**实现方式**：人物不同裁切共用源时间；撤窗时声音继续，返回接当前进度；保留一份主音轨，避免重复。

**常见误用**：人物回窗重播动作；声画错位；背景音乐掩盖话语；仅凭字幕或抽帧宣称已经听审。

**检查方法**：逐剪口原速听看并复查导出，检查截字、重声、口型、手势与动作触发是否一致。

**关联关系**：R04、R05、R17、R39。

<a id="g20"></a>

### G20 跨镜组织与克制

**检索词**：段落、节奏、叙事、取舍。

**何时查阅**：单镜都能说明一句话，连起来却重复、拥挤或缺乏推进。

**视觉操作**：按完整意思组织镜头，明确每镜新增的理解。连续过程保留对象与参照，换判断或证据时及时换场；用静止、人物、真实材料和图解调节密度。连续追问查 G25，随问题换表示查 G26，局部解释后回收总关系查 G27。

**适用前提**：全片统一来自阅读秩序和视觉习惯，不要求固定布景或每句话一段特效。情绪段落也可以由真实表演和环境承担。

**实现方式**：先用低成本时序稿检查逻辑，再精修代表镜头；确认资产品质与段落接续后扩展，避免批量复制未解决的问题。

**常见误用**：同一比喻撑完整片；方法库每种都用一次；漂亮镜头之间没有关系；为凑时长重复观点。

**检查方法**：逐镜标出新增信息，删去重复后重看整段；确认开头承诺、过程和结果对应且理解负担适当。

**关联关系**：R17、R31、R37、R40。

<a id="g21"></a>

### G21 事件光的起点、路径与落点

**检索词**：事件光、触发、传播、环境反馈。

**何时查阅**：需要用短暂光效强调一次触发、路径经过或终端状态改变。

**视觉操作**：先确定事件发生的位置、路径与结果，再分别安排发光核心、外围光晕、邻近表面反馈及衰减。保持主形体和暗部，最亮时刻对准事件；路径只在确需表达传递时出现。

**适用前提**：光效是观看提示时应保留示意性质，不把动画速度、颜色或亮度当成真实信号传播、能量或温度的测量。

**实现方式**：使用受控二维光层、三维照明或合成，并结合 G06 的触发关系、G13 的材料与环境光。

**常见误用**：接触前爆光；亮层没有来源；全场泛白；光晕遮住关键文字；所有反馈一齐消失。

**检查方法**：先关闭光晕检查起点、落点和状态变化，再恢复光效确认邻近反馈合理，信息仍清楚。

**关联关系**：R19、R20、R22、R24。

**生成提示词卡**：[P21 事件光的起点、路径与落点](08_视频生成提示词卡.md#p21)。

<a id="g22"></a>

### G22 粒子聚合与消散

**检索词**：粒子、聚合、消散、稳定身份。

**何时查阅**：需要表达分散对象汇集、群体形成轮廓或一个状态逐步解体。

**视觉操作**：为粒子设定稳定身份、起点、目标与启动条件，先形成可辨认的大形，再补必要细节。完成后保留理解时间；消散指定触发区域与方向，让观众知道原有状态怎样改变。

**适用前提**：粒子只是视觉单位时明确其示意作用；不能把数量、轨迹或随机运动冒充真实物质、数据样本或科学过程。

**实现方式**：二维或三维均可，按遮挡与深度需求选择；遵循 G05 的身份连续和 G07 的注意顺序。

**常见误用**：每帧随机重生；所有点缩成一团；文字未读清就碎裂；形体刚出现便散开。

**检查方法**：关闭辉光和拖影，确认方向、主体轮廓及形成时刻仍可辨；有数量含义时逐项核对。

**关联关系**：R02、R21、R24、R29、R40。

**生成提示词卡**：[P22 粒子聚合与消散](08_视频生成提示词卡.md#p22)。

<a id="g23"></a>

### G23 尾迹与跟随

**检索词**：尾迹、路线、历史坐标、跟随镜头。

**何时查阅**：需要同时展示对象正在前往哪里，以及已经走过的路径或状态。

**视觉操作**：将历史位置留在场景坐标中，分别更新主体、相机和历史轨迹。转向后只延续新路径，旧路径保持原位置；按叙事需要决定哪些历史痕迹保留、变淡或被比较。

**适用前提**：先说明路径代表真实行进、信息流程还是选择示意。曲线长度和画面速度没有数据依据时，不暗示实际距离、耗时或效率。

**实现方式**：二维路径、三维曲线或实拍跟踪均可；结合 G05 的对象身份与 G03 的空间参照。

**常见误用**：旧尾迹随主体整段旋转；跟随镜头中没有环境参照；转向就清空历史；接头突变造成误读。

**检查方法**：固定相机检查路线连续，再恢复跟随确认方向感；核对每条痕迹对应哪个对象和哪个阶段。

**关联关系**：R17、R20、R24、R29、R37。

**生成提示词卡**：[P23 尾迹与跟随](08_视频生成提示词卡.md#p23)。

<a id="g24"></a>

### G24 结构展开与剖面

**检索词**：剖面、爆炸分层、组装、内部结构。

**何时查阅**：外观不足以解释部件关系，需要看见内部、厚度、连接或装配顺序。

**视觉操作**：先建立完整对象，再只移开、切开或透明显示当前需要的部分。各部件保留身份、原位置来源、厚度与连接线索；解释后让观众知道它如何属于整体。

**适用前提**：真实结构依照图纸、实物或可靠资料。缺依据时采用明确的功能框图，不编造精密内部，也不以比例示意代替尺寸结论。

**实现方式**：可用实物拆解、二维剖图、受控三维或合成；参照 G02 的定位返回及 G05 的对象连续。

**常见误用**：全部部件同时飞散；厚度忽变；连接凭空消失；用虚构齿轮或线路填满内部。

**检查方法**：逐件核对来源、连接和解释用途，确认观众能定位该部件并区分实际结构与简化示意。

**关联关系**：R12、R19、R25、R27、R29。

**生成提示词卡**：[P24 结构展开与剖面](08_视频生成提示词卡.md#p24)。

<a id="g25"></a>

### G25 连续追问与条件补充

**检索词**：连续追问、问题递进、条件补充、答案边界、解释推进。

**何时查阅**：一个初步答案还不足以解释结论，需要继续询问适用条件、遗漏因素或下一步问题。

**视觉操作**：从本稿的真实疑问出发，每次回答后指出尚未解决的关键条件，再进入下一层。画面保留已确认的信息，随追问增加必要变量；问题可以由场面变化提出，不要求每次口播问句。

**适用前提**：后一个问题确实由前文的不足产生；新条件有依据或明确标成假设。锁稿时只组织已有内容，不擅自新增问句或主张。不能为制造悬念藏掉会改变前面结论的重要事实。

**实现方式**：用讲者、实际材料或图解承接问题，每轮只突出本轮新增条件。需要更换表示方式查 G26，累积关系较多时查 G27。

**常见误用**：把每句改成问答；连续设问却不给有效回答；预设惊人结论后硬凑条件；新增变量却清空旧限制。

**检查方法**：逐轮说清回答了什么、还缺什么、为何值得继续；最终结论能够回到已给出的条件与证据。

**关联关系**：R06、R12、R27、R31、R37、R38。

<a id="g26"></a>

### G26 根据问题切换图形与比较基准

**检索词**：表示切换、比较基准、图形选择、问题变化、口径。

**何时查阅**：追问从数量转到流向、条件、构成或流程，原有画面已经无法准确承载新问题。

**视觉操作**：先说清问题与指标怎样改变，再选择更合适的表示。问多少可用同尺度比较，问流向可用去向关系，问怎样运转可用过程。切换时保留对象名称与必要参照，让观众知道正在换问题。

**适用前提**：同一指标的比较保持口径；改单位、时间范围、统计对象或分母时明确交代，不把新图冒充旧图的连续数值变化。绝对数量增加不等于比率提高，前后对比也不单独证明因果。

**实现方式**：二维、实物场景或空间图均可。保留一个对应线索交接注意力，必要时短暂并列两种表示；准确阅读条件参照 G08、G09。

**常见误用**：每个问句都换一种图；不同尺度直接比高低；图形变漂亮却丢掉条件；相同颜色在新图里悄悄换义。

**检查方法**：观众能说出新问题、新基准与旧图的对应；不能直接比较的量没有被动画暗示为可比。

**关联关系**：R15、R16、R17、R25、R31、R33、R34、R35。

<a id="g27"></a>

### G27 逐步建图与总图回收

**检索词**：逐步建图、总图回收、关系累积、局部与整体、解释结构。

**何时查阅**：多个局部解释属于同一系统，观众需要理解这些部分最终怎样共同影响结论。

**视觉操作**：先建立必要的关系骨架，随局部解释逐步增加对象与条件，保留位置线索。在需要定位的阶段或结尾回到更新后的总图，不必每讲一步都返回；回收时显示已解释的路径与仍未知的部分。

**适用前提**：总图中的关系有依据，确实能帮助理解整段。情绪、独立案例或简单判断不必强行汇成系统图，也不预先画满尚未成立的结论。

**实现方式**：可用二维关系图、真实流程全貌或空间结构，采用稳定身份和位置线索；当前区域突出，其余已知关系退为参照。结合 G02、G05。

**常见误用**：每一步都重画全图；分支越来越多无法阅读；为凑总图添加虚构联系；收尾只堆回缩略图，没有关系回收。

**检查方法**：从任一局部能找到整体位置，结尾能复述主要关系及边界；删去装饰后，累积的解释仍然成立。

**关联关系**：R12、R14、R19、R25、R29、R32、R40。
