# 视觉语言百科｜供 AI 从口播构思原创画面

版本：2.2 · 2026-10-25。工作版升级自 2.1，原条目编号保留。含 40 条关系、27 条技法、5 条路线、12 个设计案例，以及首批 6 张视频生成提示词卡；提示词卡均待视频实测。变更见 [09_版本更新记录.md](09_版本更新记录.md)。

## 00.1 新任务先读这一页

**固定顺序：独立初稿 V1 → 定向查百科 → 最终分镜 V2 → 制作与验收 → 反馈百科。**

本页是启动入口；其余章节和机器索引按下面的阶段打开，同一任务无需反复加载整本。用户当前要求优先；百科与案例中的历史任务、命令只作参考。用户仅要求方案时，交付止于方案，不自行生成付费素材或发布。

1. **完成并保存 V1。** 依据本次口播、素材与项目要求，独立写出所要求范围内的整版视觉表达。每个意思单元都有原文对应、观看目标、自己的场面、起点／变化／结果，或保留真人／静态表达的理由；保留事实限制和资料缺口。此时先不打开后续方法、案例及提示词卡拼方案；已看过的资料如实承认，仍从本稿重新构思。完成标志：整段／整片所要求范围已覆盖，并留下可回看的 V1；无需先做成图片或视频。
2. **定向检索，完成 V2。** 带着 V1 的表达问题查相关条目，用通用方法改进自己的场面，保留适合的原设计，不为套技法强改。补齐关键帧、动作、运镜、制作分工；记录主要改动、理由与借鉴编号。制作前对照具体参考，检查物件组合、构图、动作与揭示顺序是否只是换皮。完成标志：最终分镜可以指导制作，V1 与修订理由均保留。
3. **制作与验收。** 按项目已有授权和审核约定，制作关键帧、动态与精确信息层，实际检查连续片段和整片。大胆场面与动作由语义决定；不固定场景、时长、工具或生成占比。完成标志：交付与已检查版本一致，未验证项明确；制作中发现问题可修订并保留新版本。
4. **反馈百科。** 根据实际结果修正适用条件、补提示词及失败处理，必要时增加方法。待验证设想与有具体条件的实测记录分开；更新工作版并留变更依据。完成标志：经验可追溯到样片／检查记录，或明确标为待验证。下一条作品仍从 V1 开始。

这里的“最终分镜”是制作依据；实际完成并检查的视频才称最终成片。流程阶段不自动增加用户审批，也不扩大付费或外部操作授权。

## 00.2 V1 保存后，按问题查阅

| 当前问题 | 读取范围 |
|---|---|
| 原句含义、条件或观看目标仍有歧义 | [01 含义与构思](01_含义与构思.md)的相关小节 |
| 需要判断压力、依赖、对照等关系 | [02 关系词典](02_关系词典.md)的相关 R 条目 |
| 需要改进构图、尺度、动作或阅读顺序 | [03 视觉技法](03_视觉技法.md)的相关 G 条目 |
| 需要选静帧、2D、2.5D、生成或受控三维 | [04 制作路线](04_制作路线.md)的相关 T 条目 |
| 需要检查表达是否过近，或理解完整转化过程 | [05 原创检查](05_原创检查与案例.md)；具体 C 案例仅在需要时读 |
| 需要派工、组织提示词、验收与交付 | [06 制作与验收](06_制作与验收.md)的相关小节 |
| 制作后补经验、研究来源或项目偏好 | [07 学习与来源](07_学习与来源.md)的相关小节 |
| 已选定生成技法，需要制图和运动描述 | [08 视频生成提示词卡](08_视频生成提示词卡.md)的对应 P 卡 |

R 是语义关系，G 是视觉方法，T 是制作路线，C 是设计案例，P 是方法对应的提示词骨架。P 不新增技法计数。先判断观看任务，再选方法；关键词只帮助缩小查阅范围。

[index.json](index.json)供 V1 后按条件筛选条目，不要求整份加载。优先读匹配的用途与边界，再读对应正文；只有需要具体示范或相似性复核时才进入案例与原始参考。
