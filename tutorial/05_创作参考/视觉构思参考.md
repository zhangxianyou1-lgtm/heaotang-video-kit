## 让画面表达关系

先找到文字中的矛盾、关系、态度和变化，再决定用什么物件。画面可以把影响力变成体积，把时间变成距离，把成功经验变成束缚，也可以用一个静止细节留下余味。内容需要清楚解释时，直接表现业务和结构；内容需要情绪、悬念或反讽时，再选择隐喻。

构思前简要确定：

| 要理解的内容 | 对画面的影响 |
|---|---|
| 表层事件：这一段谈什么 | 观众从哪里认出题意 |
| 核心关系：依赖、错配、交换、循环、挤占或转变 | 对象之间怎样相处 |
| 讲述态度：惊讶、冷静、惋惜、讽刺或赞叹 | 美术语气和观看距离 |
| 身体感受：被压住、失去支点、松开、悬而未决 | 尺度、空间、光线和运动 |
| 值得发现的另一层意思 | 画面的意外之处 |

大胆可以来自巨大尺度，也可以来自一个空位、一处磨损或安静构图中的小异常。一个系列可以有共同气质，同时采用准确信息画面、真实素材、平面动画、2.5D、写实生成和静场形成强弱变化，避免所有段落都重复同一种流程图。

## 可以选用的构思方法

| 方法 | 可见做法 |
|---|---|
| 尺度错置 | 让真正支配局面的对象获得体积，与普通尺度物件同场 |
| 用途反转 | 保护、奖励或连接的东西产生相反作用 |
| 跨域嫁接 | 用另一个领域中相同的关系解释当前问题，接合处仍有逻辑 |
| 材质变义 | 通过重量、软硬、脆性、透明度与变形表达后果 |
| 内外冲突 | 正面与背面、包装与内部、台上与台下互相揭示 |
| 空间化 | 把门槛、时间和流程变成距离、坡度、夹缝或回路 |
| 同场矛盾 | 让诱惑与危险、繁荣与空洞同时可见 |
| 缺席与痕迹 | 用空位、磨损、残留和被挤开的空间表达不可见的成本 |
| 视角揭露 | 从背面、底部、剖面或近处重新理解熟悉对象 |
| 语境改写 | 对象保持不变，改变环境和邻接物，让含义翻转 |

熟悉的隐喻可以继续发展：钥匙是入口，钥匙长成堵住入口的结构则表达了另一层关系。选用哪一种方法、如何组合，由当前段落决定。

## 画面与口播的四种关系

1. **直接阐明。**把区别、操作、结构和结果讲清，创造力体现在比例、层级和观看位置。
2. **向外延伸。**文字讲事件，画面表现沿同一逻辑发生的后果或情绪。
3. **形成反讽。**让荣耀与代价、丰富外观与单一去向同时成立，靠结构表达判断。
4. **保留余味。**话已讲明白时，用静场或细节给观众观看时间，不必逐字兑现。

用户已确认的口播内容与顺序作为叙事依据。艺术夸张表达观点；软件操作、核验结果和设备结构按实际业务参考呈现。缺少实机素材时，使用本包实机复刻规范制作可交互界面并实际录屏，不能用抽象动画代替尚未展示的操作。

## 生图提示词写法

先单列一句“视觉命题”，说明这张图增加了什么含义。再把希望看见的状态写成完整提示词：

> 媒介与整体气质 → 可见场景 → 最关键的对象关系 → 主次与机位 → 材质与光线 → 支撑含义的细节 → 本次画幅和技术要求。

“压迫感”落实为逼近、遮挡、通路收窄或失衡体量；“表里不一”落实为外壳、支架与连接的差别。重要物件使用明确名词，写清谁支撑谁、哪里连接、什么遮挡什么。静态提示词描述已经可见的一个状态；连续动作写在视频提示词里。中文密集界面、金额和长文字优先在实际软件或图层中准确渲染。

## 首帧、尾帧与完整视频提示词

动作拆解、秒点使用、参考帧准备与动态验收，另见[连续动作设计与视频提示词](连续动作设计与视频提示词.md)。先有主体事件，再决定如何运镜；不要用微推替代本应发生的动作。

某段确定采用生成视频时，提供三份可单独复制的完整提示词，并明确引用哪张参考图：

- **首帧：**完整场景、主体身份、位置、尺寸参照、机位、初始状态、光源和材质。首帧本身应是一张成立的画面。
- **尾帧：**参考所选首帧，完整说明结束时可见的场景；交代哪些特征延续、哪些发生变化，以及动作是否已经完成。不能只写“同首帧，改成完成”。
- **整段视频：**首尾状态之间怎样过渡。说明主体、相机、焦点或光线各自怎样运动；动作从哪里开始、沿哪里发生、如何收束，给结果留出实际观看时间。时长服从口播槽和用户要求，不通用固定6秒。

生成前可检查人物身份与服装、道具结构、座次、空间方位、接触与受力、主光和终态是否对应。生成后查看真正输出，不只检查提示词。新生成片的模型声音是否采用按本期安排决定，不默认混入已确认口播+BGM主音轨。

## 代表性构思例子

以下沿用旧艺术总纲中的例子，帮助理解方法；不直接套进新项目。

**工具箱展开成学校：**“以为拿到轻便工具，却面对一整套学习负担。”普通大小金属工具箱与纸板折叠课堂同场，课堂通过箱内折脊和支架展开。关键在于普通工具与巨大负担的尺度反差，以及结构确实连接，材质、道具和机位均可另选。

**把光送到背面：**“想看明白漂亮表面后，真做时才会遇到的细节。”面具正面保持光滑，检查灯进入背面夹层，逐步照出原本存在的胶、螺钉和维护痕迹。物体不必变形，注意力和观看发生变化也能形成叙事。

**许多入口通向同一房间：**“选择看似丰富，去向却没有改变。”不同门面、材质和广告的背后，走廊最终接进同一个房间。通过剖面或高处视角同时展示外观和去向，让结构自己表达。

**有效的系统很安静：**玻璃屋顶上雨水沿细密导流槽流向两端，下面的小桌干燥整洁。用没有发生的混乱表现价值，不要求每段都堆满物件和动效。

参考的价值在于关系成立、观看有发现、动作可实现。新题材应产生自己的画面，具体分镜与美术继续交给Claude。
