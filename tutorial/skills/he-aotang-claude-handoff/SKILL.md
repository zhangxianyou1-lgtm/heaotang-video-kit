# 和奥堂视频与 Claude 交接

保持直接、适度的大局指导。用户当次要求优先。

## 分工

GPT负责理解口播、提供大体思路与核心信息，安排真人、动画、实机演示的段落与时间，制作本次需要的实机素材，并在回交后完成最终剪辑。

教程与任务包在ChatGPT Codex中管理。GPT管理的生成片使用ChatGPT图像能力制作首尾帧，再用LibTV CLI生成视频；具体顺序与来源记录按[先读我的生成平台分工](../../00_先读我.md)。

Claude负责动画的具体分镜、画面设计、构图、动作、转场和美术风格，自主完成视觉创作；同时负责全片BGM选配与混音。任务单给创作方向，具体怎么表现交给Claude。

## 任务与交接包

每段用简短条目说明：对应口播与时间、观众应理解的核心意思、必要的业务事实和衔接要求。字幕与人物小窗的预留、总时长和交付格式集中列一次；具体数值沿用本项目要求。细分镜、逐帧动作、道具、构图及色彩方案由Claude设计。

收到视频后提取完整音频。默认给Claude的包只放一份完整音频和必要任务文件、文字时轴。原视频、实机录屏、截图、程序及本地备份留给GPT剪辑；有明确额外参考需求时再加入所需文件。

BGM任务覆盖全片，按用户要求采用免费可商用音乐，回交口播+BGM主音轨、对齐的BGM分轨及来源许可说明。保留口播内容、顺序和速度，技术规格依本项目时间基准。

长录屏用于验收和挑选素材，成片按对应口播截取必要片段。实机制作需要时使用 [client-scene-recreation](../client-scene-recreation/SKILL.md)。

回交统一核对四类成果：①动画与音频（含全片口播+BGM主音轨、对齐BGM分轨及许可说明），②对应封面，③发布标题，④介绍/描述。封面与文案由Claude完成；这些成果不增加默认输入包的原视频或本地演示素材。

更新交接时同步启动词、任务文件和ZIP，检查没有残留相反分工或缺失文件引用。后续只使用当前交接版本。


## 字幕与小窗

用户2026-11-12确认的默认位置：9:16视频的口播字幕组中心固定在画面高度80%处。1080×1920时为 x540、y1536，单行、双行共用此中心，其他分辨率按比例换算。预留 y1440–1640 为完整字幕区，常规双行底框约 y1458–1614，不再沿用 y1745 的低位字幕。保留当期已确认的字体、底框样式、文字和时间。

任务单集中注明字幕区与小窗预留即可，Claude仍自主设计分镜、画面和美术。关键文字、操作控件及人物小窗避让字幕区；小窗底边建议在 y1420 及以上（y≤1420），与字幕框至少留20像素间距。冲突时调整小窗或画面构图，保持字幕位置。GPT在实际成片中检查单行、双行、真人、动画、实机及小窗画面的遮挡与位置。

用户当期另有明确要求时优先。更新布局规范不自动批量重剪其他历史成片。
