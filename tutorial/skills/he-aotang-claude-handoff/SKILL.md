# 和奥堂视频与 Claude 并行子智能体交接规范

保持“锁死工程坐标契约、100% 放开视觉语法创造”的核心原则。用户当次要求优先。

## 五大模块分工与交接边界

GPT（Codex）担任全片总导演：完成 5 分钟绿幕原片去口误与书房背景抠像锁帧（`base.mp4`）、排布五大视觉模块（`D` 真实新闻/人物实证、`R` 高逼真客户软件仿真录屏、`A` Claude 动画、`G` 首尾帧＋MiniMax-H3 奇观、`P+PIP` 全屏真人与知识点专门开口小窗）及 `B` 官方片头/4.5s 片尾总 Logo，并在回收素材后完成小窗裁切嵌回、统一字幕与 `-16 LUFS` 响度标准化总装。

Claude 独立负责全部 `A` 槽原创动画、全片 BGM 与词级 SFX 混音、竖屏封面及发布标题描述：
- **严禁预设风格或举例锚定**：GPT 填写任务单时只写完整口播原句、准确帧槽 `[start,end)`、核心商业意思、数字口径、邻镜防撞意象提示与 `pip_window` 小窗开口坐标，**绝不写“2.5D等轴/卡片/分屏”等具体画法举例**。
- **强制目录隔离与并行子智能体盲审**：在启动词中要求 Claude 在空白新目录作业（不读历史旧工程、`side-session-notes` 或本地旧版 2D 动画技能），通过「1 总导演统筹错开媒介 → N 路并行子智能体单槽深雕（让字长在器物与场景里）→ 1 独立审片子智能体横向盲审打回返修」保障段段惊艳、绝不雷同。

## 字幕带、小窗专门开口与总装音频契约

1. **统一字幕带**：9:16（`1080×1920`）口播字幕由 GPT 最后统一压在中心 `x540 / y1536`（隐形避让安全区 `y1440–1640`，严禁 Claude 渲染可见占位框）。
2. **知识点人物小窗开口（`pip_window`）**：每期核心知识点段落至少规划 `3` 处小窗开口（`rect/square/circle`，累计 `≥15%`，底边死锁 `bottom_y ≤ 1420`）。Claude 按任务单坐标在动画中留出该开口净空，GPT 总装时从 `base.mp4` 对应时间码裁切真人嵌入。
3. **零采样误差音轨与 `-16 LUFS` 总装响度**：Claude 回交的三条 `48kHz` WAV（主音轨、BGM分轨、SFX分轨）采样数严格等于 `total_frames × 1600`，且 `B_intro / B_outro` 包装区间为全零静音。GPT 总装补入片头/片尾独立音效后，统一执行整轨 `-16 LUFS`（真峰值 `≤ -1.0 dBTP`）响度标准化。
