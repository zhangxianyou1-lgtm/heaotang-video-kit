# 和奥堂｜视频来了之后怎么做

版本：2026-11-17 R6.1。本包在ChatGPT Codex中运行。方案、提示词、首尾帧由ChatGPT负责，LibTV负责视频生成。本版明确平台分工，保留R5.2的动作研究、视觉隐喻、真实演示和动态验收流程。

先读[R6.1规范](../R6.1_视觉风暴与零穿帮规范.md)与[多模型性能压榨指南](../多模型性能压榨指南_GPT_MiniMax_Claude.md)。每期从自身商业冲突原生推导独立首镜与结构隐喻，代码之桥仅为历史案例。原研究来源与证据边界保留，不覆盖R6.1执行规则。

## 在另一台电脑开始

1. 解压本教程包。需要既有栏目包装时，同时解压另附的“和奥堂_栏目包装素材_20261112.zip”（含`00`账号片头与`01/02/03`栏目无声MP4＋匹配WAV音效），放在教程目录旁边或本地`branding/`忽略目录下。
2. 在ChatGPT Codex中打开本目录，提供新一期原视频和当期最新文稿；若当次仅先规划纯文字新稿（指定写MD+JSON方案/提示词/生图），直接提供新文稿即可开始。先核对已有资料，不重复索要已经提供的信息。
3. 复制 [01_直接复制给AI的启动词.txt](01_直接复制给AI的启动词.txt)，连同素材一起发送。AI先读 [02_收到视频后的完整流程.md](02_收到视频后的完整流程.md) 再执行。
4. 首轮拿到“Claude轻量交接包”和“生成方案”。适合软件演示但缺素材的部分由GPT制作逼真界面并实际录屏。你明确只要某一项时，按当次范围完成。
5. 把Claude轻包发给Claude。它只需完整音频和任务文字；原视频与本地实机素材由GPT保管、用于最后剪辑。
6. 按当次范围由ChatGPT制作首尾帧，后续由Codex调用LibTV CLI生成视频；两阶段分别验收。需要的素材回齐后，把回交文件路径给GPT继续剪辑。
7. 最后收取完整版、可编辑工程、封面、发布标题和描述，并检查实际成片。过程与验收均有模板可用。

## 一句话记住分工

GPT负责理解内容、安排段落、做逼真演示、统筹素材和最后剪辑；Claude自主设计动画分镜与美术，完成全片BGM、封面、标题和描述。Claude自主设计完整的A段分镜与运动，并按实际动画回交SFX事件；GPT提供已确认的整片媒介分配、完整口播与时间槽。

## 生成平台分工

所有教程、提示词、任务包和执行记录由ChatGPT Codex读取、编写和管理。图片与视频使用不同的生成入口：

| 工作 | 执行入口 |
|---|---|
| 创意方案、口播对齐、动作设计、完整提示词 | 当前ChatGPT Codex会话 |
| 首帧、尾帧及需要的图片修改 | ChatGPT内置图像生成能力 |
| 由已选首尾帧和视频提示词生成运动镜头 | Codex调用已登录的LibTV CLI |
| 下载、实际观看、动作验收和最终合成 | ChatGPT Codex统筹本地工具 |

先在ChatGPT生成首帧并实际看图，再引用选定首帧编辑尾帧，核验同一场景、人物、机位和动作起止状态；只要求图片时到此交付。需要视频且授权明确时，再将选用帧与视频提示词交给LibTV，按原口播实际时长完成动作并验收。

当前ChatGPT图像工具不可用时，先完成提示词并如实说明缺项，不默认改用LibTV生图。用户后来明确更改平台时以新要求为准。历史由LibTV生成的图片继续标记真实来源，不能改称ChatGPT生成；只更新分工不触发历史媒体重生成。Claude的既有动画与BGM交接继续按当期任务范围处理。

## 本包已落实的新标准

- Claude默认输入：一份完整音频＋必要任务文字／文字时轴；不放原视频、长录屏和本地工程。
- Claude回交四类成果：动画与音频、封面、标题、介绍／描述。
- GPT担任总导演按语义动态统筹五大视觉模块（①D真实新闻/人物3候选择优实证；②R高逼真客户软件仿真录屏；③A零预设风格+并行子智能体单段深雕盲审动画；④G首帧奇观+MiniMax-H3单向变化；⑤P全屏真人15%–35%双边锁死 + 核心知识点≥3处PIP专门开口小窗y≤1420）。
- 字幕组中心固定在画面高度80%：1080×1920时x540/y1536；预留y1440–1640。总装合并片头/4.5s片尾总Logo独立音效后，统一标准化至 -16 LUFS（真峰值 ≤ -1.0 dBTP）。
- 软件演示要真正可操作并录屏，功能、真实性、脱敏分别核验；鼠标按最终成片像素检查。
- 每期开场`00:00–00:06`固定为完整6秒`G01`奇观首镜（正片其余独立G下限4秒），`6–12s`真人P，`12–15s`核心R预览；和奥堂共配备 **4 支官方暗场片头**（`00_账号片头_和奥堂AIclub.mp4` 6.0s［4.4s后可切］＋ 3 支栏目片头 `01_真实需求探针 / 02_AI实战实录 / 03_技术细节拆解` 各 5.0s［3.3s字组落定，可取 `3.5–5.0s`］＋ `音效/*.wav`），**绝不放00:00抢首镜**，按当期策略在 `00:15` 后钩子切口插入独立 `B_intro` 槽或挪至片尾收束。
- Claude主音轨已含口播和BGM时，最终只接这一条主轨，不再重复叠加原口播和BGM分轨。

## GPT负责的G生成片创作参考与提示词要求

以下用于GPT的生图与生视频任务。Claude的A动画以完整口播、整片安排、语义目标和工程规格为输入，创作参考按需选读，历史案例中的人物、道具、配色和动作约束不作为A任务要求。

- **三大母本、规则隔离与口播原生推导**：结合 `05_创作参考/让画面有第二层意思_巫师财经总纲.md`、`05_创作参考/视觉语言百科_v2.2/00_开始使用.md`、`05_创作参考/15支视频物体视觉方法/02_物体空间与镜头表现.md`（已剔除阿畅）。已隔离作废 `15支视频` 历史“尽量不生成人物 / 默认不新增人物与手部”限制，人物与手部依《巫师总纲》开放选用；口播是创作输入，独立核实不是生图前置条件；**按 V1→V2 从当期口播重新推导场景与物件，不套示例模板，亦不另设禁用某些材质的新限制**。
- **首帧即奇观＋单向五步连续动作补强**：独立生成镜头（尤其 `G01` 首镜）第 `0.0` 秒**首帧本身必须已同场立住超现实尺度反差或结构异变**（严禁把首帧画成普通日常白墙、门口拿手机或正常办公照，把奇观留到尾帧）；首尾帧必须构成**单向不可逆物理状态差**（严禁“完好→崩塌→完好”U型折返陷阱），落实“奇观蓄势初态 → 可见触发与物理接触 → 单向主变化推进 → 次级物理反应 → 终态减速停留”。
- **≥200字高密度细节门槛＋零工程词污染**：每条首帧、同源尾帧、视频运动提示词均须写满 ≥200 个纯中文字符的可见场景、尺度参照、材质纹理、光线与动作细节，**严禁混入 `字幕`、`y1440`、`后期图层`、`乱码`、`假字` 等工程指令词**（底部留空直接描写干净平整的前景地面或台面材质）。
