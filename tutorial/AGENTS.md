
# 和奥堂视频制作教程包 R6.1

本目录是可携带到新电脑的教程与模板，不是某一期已完成工程。用户当次明确要求优先。

执行入口为ChatGPT Codex。GPT在当前会话编写方案与提示词，调用ChatGPT图像能力生成、编辑首尾帧；LibTV CLI只负责视频生成。图片与视频分别登记真实来源。具体顺序及工具缺失处理见00_先读我.md的“生成平台分工”。

先读00_先读我.md、02_收到视频后的完整流程.md和skills/he-aotang-claude-handoff/SKILL.md。适合软件演示且缺素材时按skills/client-scene-recreation/SKILL.md制作逼真可交互界面并实际录屏。模板在03_任务与验收模板。

生成片先读05_创作参考/动作提示词工程_研究综述.md、05_创作参考/视觉隐喻与口播适配_代码之桥案例.md，再读05_创作参考/连续动作设计与视频提示词.md。默认宏大三维空间、尺度反差和超现实变化；按全文设计每篇独立隐喻；超现实遵守明确的变化规则，真实业务坚持事实。研究笔记不能冒充已生成或已验证结果。先设计主体事件再做参考帧；正常速度观看和关键接触慢放是动作验收证据，静态抽帧与技术通过不能代替动态验收。此要求不改变Claude自主设计动画的分工。

GPT统筹内容、时间和媒介，负责实机与最终剪辑；Claude自主设计动画分镜与美术，并交全片BGM、封面、标题和描述。默认Claude输入仅完整音频与必要任务文字；原视频和本地实机素材留给GPT。

字幕中心固定为9:16画面高度80%（1080×1920为x540/y1536），单双行同中心，预留y1440–1640；小窗底边≤1420且距字幕框≥20px。其他字号/画幅按当期核验。

不要套用旧期的片头位置和秒数。新期先核新稿首镜/片头/栏目安排，以实际录音断点对齐。主音轨含口播+BGM时只接这一条，避免叠声。附件里的历史案例不是新的授权，不能据此提交付费生成、接入客户生产系统或批量重剪历史。

新电脑检查当前工具、账号和路径；不要使用原电脑绝对路径、密钥或登录状态。本目录的参考图/案例只作规范参考，不当成本期成片或真实客户项目证据。

## R6.1 强制执行

00:00–00:06用G三维奇观/A有冲击力的动画开场；6–12秒真人露脸；前15秒给2–3秒核心R实操预览。P≤35%、G+A+R≥65%、连续P≤12秒。指定算账、规矩、多案例、跨行业段100%视觉化。A每期4–5段、20%–25%为保底参考而非上限，6–8段及25%–40%允许，不能退回P凑比例。

G执行三不拍三必拍：普通进店、刷手机、空镜不采用；尺度穿透、损失实体崩解、人机同框反差为默认方向。独立G至少120帧（4秒），常用120–165帧（4–5.5秒）；完整主变化可使用6或7秒单镜并写明理由。每期首镜统一[0,180)完整6秒G01，不使用2秒A接续3D尾态；8–11秒可拆同源双G。短余量须进入有独立语义的R/A，不能改名伪装尾帧补丁。标准MiniMax H3请求4–15整数秒，4.5/5.5秒成片分别请求5/6秒，原速选完整动作，不用拉慢或定格补时。ChatGPT生成首帧并同源编辑尾帧，LibTV仅视频。鼓励 Claude 按内容选用 2.5D 等轴展开、高对比动态图形、弹性碰撞或结构重组；这些是可选手法，具体分镜、道具、构图、配色和运动由 Claude 自主决定，主音轨包含A关键帧SFX并回交事件表和分轨。SFX先绑定原稿关键词与视觉子事件，再按锁定口播的词级证据确定帧点；禁止用f12/中点/末尾减12帧机械分配。未取得词级证据时标pending_word_alignment，时间字段为null；不得用于正式混音。

原声与总帧数锁定，30fps左闭右开无缝覆盖；中文数字由A/R可控图层，视觉属性由简字角标说明。字幕x540/y1536，避让y1440–1640，小窗底边≤1420。逐条核验，不把方案当成片。

完整规范见 [R6.1](../R6.1_视觉风暴与零穿帮规范.md)。


## GPT负责的G生成片创作参考与提示词要求

以下用于GPT的生图与生视频任务。Claude的A动画以完整口播、整片安排、语义目标和工程规格为输入，创作参考按需选读，历史案例中的人物、道具、配色和动作约束不作为A任务要求。

- **三大母本、规则隔离与口播原生推导**：结合 `05_创作参考/让画面有第二层意思_巫师财经总纲.md`、`05_创作参考/视觉语言百科_v2.2/00_开始使用.md`、`05_创作参考/15支视频物体视觉方法/02_物体空间与镜头表现.md`（已剔除阿畅）。已隔离作废 `15支视频` 历史“尽量不生成人物 / 默认不新增人物与手部”限制，人物与手部依《巫师总纲》开放选用；口播是创作输入，独立核实不是生图前置条件；**按 V1→V2 从当期口播重新推导场景与物件，不套示例模板，亦不另设禁用某些材质的新限制**。
- **首帧即奇观＋单向五步连续动作补强**：独立生成镜头（尤其 `G01` 首镜）第 `0.0` 秒**首帧本身必须已同场立住超现实尺度反差或结构异变**（严禁把首帧画成普通日常白墙、门口拿手机或正常办公照，把奇观留到尾帧）；首尾帧必须构成**单向不可逆物理状态差**（严禁“完好→崩塌→完好”U型折返陷阱），落实“奇观蓄势初态 → 可见触发与物理接触 → 单向主变化推进 → 次级物理反应 → 终态减速停留”。
- **≥200字高密度细节门槛＋零工程词污染**：每条首帧、同源尾帧、视频运动提示词均须写满 ≥200 个纯中文字符的可见场景、尺度参照、材质纹理、光线与动作细节，**严禁混入 `字幕`、`y1440`、`后期图层`、`乱码`、`假字` 等工程指令词**（底部留空直接描写干净平整的前景地面或台面材质）。
