# pstack-poteto (Curated Verification & Review Foundation)

Curated from Lauren Tan (`@poteto`)'s [`cursor/plugins/pstack`](https://github.com/cursor/plugins/tree/main/pstack) (MIT License) as the **verification & low-human-review pillar** of the Three-Masters Engineering Foundation (alongside **Matt Pocock** and **Ponytail**).

## Included Upstream Skills (14, zero name collisions)

- `interrogate` — Adversarial review where **only findings proven by a real run survive**.
- `blast-radius` — Trace hidden downstream breakage and prove the core safety fact by running code.
- `create-verification-skill` & `maintain-verification-skill` — Generate and maintain `.agents/skills/verify-<app>/` + `features/` map so agents verify the running app end-to-end with captured evidence.
- `correct` — Eliminate repeated agent mistakes structurally (Architecture → Types → Lint/CI → Behavior Tests → Docs last).
- `benchmark-checklist` — 7-question empirical audit before trusting any performance number.
- `architect` — Sketch and compare two module/type shapes before crossing boundaries.
- `sharpen` — Rewrite a prompt deeper (top-pro gap, rawest material, methods, external proof).
- `how` & `why` — Read-only architecture walkthrough (`how`) and git/PR history rationale (`why`).
- `arena` & `pstack-swarm` — Parallel candidate bakeoff/grafting (`arena`) and slice/race fan-out (`pstack-swarm`).
- `in-your-own-words` — Restate goal and problem before execution.
- `poteto-principles` — Complete reference of all 24 `@poteto` engineering principles.
