## R6.0 强制执行

00:00–00:06用G三维奇观/A强2.5D开场；6–12秒真人露脸；前15秒给2–3秒核心R实操预览。P≤35%、G+A+R≥65%、连续P≤12秒。指定算账、规矩、多案例、跨行业段100%视觉化。A每期4–5段、20%–25%为保底参考而非上限，6–8段及25%–40%允许，不能退回P凑比例。

G执行三不拍三必拍：普通进店、刷手机、空镜不采用；尺度穿透、损失实体崩解、人机同框反差为默认方向。独立G时槽必须120–165帧（4.0–5.5秒）；8–11秒拆两镜接力，余量不足4秒交A/R，不能新建碎片G。生成请求另按当前模型最低时长（Seedance 2.0最低4秒，AutoTake最低5秒）校验。ChatGPT生成首帧并同源编辑尾帧，LibTV仅视频。Claude以2.5D空间、弹性碰撞、网格重组完成A，主音轨包含A关键帧SFX并回交事件表和分轨。

原声与总帧数锁定，30fps左闭右开无缝覆盖；中文数字由A/R可控图层，视觉属性由简字角标说明。字幕x540/y1536，避让y1440–1640，小窗底边≤1420。逐条核验，不把方案当成片。

## R6.0 反平庸与高留存强制复查

阅读全文及实际口播；逐段检查主变化和语义，不只审G镜头。运行 `python tools/check_r60_plans.py`，核验帧覆盖、首镜、前15秒预览、真人比例和最长连续段、G子镜120–165帧及指定视觉化区间；填写A任务数、连续槽数和时长。视觉判断与真实字口核验另记，不用自动通过代替看与听。

| 原句／帧槽 | 旧画面问题 | 新动作与结果 | 制作方 | 核验依据／缺项 |

| 填完整语义与实际帧区间 | 明确遗漏或平淡处 | 可见触发、变化、终态 | P/G/R/A | 方案/动态/声音分别记录 |

## 工程与协作

保留既定背景、真实人物与桌面、前处理代码和30fps音画基准。主音轨持续不断，A关键帧SFX由Claude混入；最终仅接一条完整主轨。标准字幕区和HTML真实操作不变。

[协作入口](agent-workflow/SKILL.md)与[协议](agent-workflow/references/protocol.md)在有独立交付项时启用；明确小改动直接完成。此包是Codex驱动流程加本地工具，不是已经接通所有平台的无人值守服务。图像、LibTV、Claude能力以当次工具和实际回交为准。
