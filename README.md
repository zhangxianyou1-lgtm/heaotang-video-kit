## R6.1 解决了什么

1. **装回三大视觉母本，彻底松绑物件限制**：完整内置 [《让画面有第二层意思·巫师财经总纲》](tutorial/05_创作参考/让画面有第二层意思_巫师财经总纲.md)、[《视觉语言百科 v2.2》](tutorial/05_创作参考/视觉语言百科_v2.2/00_开始使用.md) 与 [《巫师10片物体空间方法（已剔除阿畅）》](tutorial/05_创作参考/15支视频物体视觉方法/00_开始阅读.md)。恢复“口播即创作输入，独立核实不是生图前置条件”；**不预设、不限制用什么具体物件、材质或场景，完全由 AI 根据当期口播自主构思第二层意思**。
2. **结合 R5.3 / R5.4 连续动作补强**：保留 [动作提示词工程](tutorial/05_创作参考/动作提示词工程_研究综述.md) 与 [连续动作设计](tutorial/05_创作参考/连续动作设计与视频提示词.md) 的五步物理动作链（`初态→可见触发与接触→变化前沿推进→次级反应→结果停留`），拒绝静态微推与跨空间溶解。
3. **强制 ≥200 中文字符高密度提示词门槛**：首帧、同源尾帧、视频运动提示词每条均须写满 ≥200 字的具体场景、尺度参照、材质纹理、光线与动作细节，杜绝因提示词简略导致的画面粗糙。
4. **保留 R6.0 + H3 四秒零穿帮工程底盘**：`P ≤ 35%`、连续 `P ≤ 12秒`（九期实控 `≤ 10.0秒`）、`G ≥ 120帧（4秒）`、6秒完整 `G01` 首镜、Claude 2.5D 扩容、词级语义 SFX 门禁及 `tools/align_sfx_words.py` 对齐工具。

## 以后怎么用

解压整包，在 Codex 打开目录，复制 [启动词](START.txt)，提供当期视频/稿件。先按 [pipeline](pipeline/README.md) 做顺畅基准片，再按 [完整流程](tutorial/02_收到视频后的完整流程.md) 排画面与交接。
